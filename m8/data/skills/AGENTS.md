# skill 安装

> **这份文件是写给 AI agent 看的。** 你是被叫来「给 M8 装一个 skill」的话，
> 照下面的形状放就行，不要自己发明结构。
>
> 这个目录本身不进 git（`m8/data/skills/*` 全被忽略），只有本文件和 `.gitkeep` 例外 ——
> 所以别人 clone 下来能看到这份说明，但看不到已经装好的包。

## 一个 skill 是目录，不是文件

```
m8/data/skills/
└── 我的skill/
    ├── SKILL.md          必需，正文
    ├── references/       可选，参考资料
    └── scripts/          可选，示例代码
```

**空目录不算 skill**，会被静默跳过。

## 最小可用形状

```
m8/data/skills/翻译规范/SKILL.md
```

```markdown
---
name: 翻译规范
description: 中译英时保持术语一致；产品名保留原文。
---

# 翻译规范

（正文。写成给一个刚入职的同事看的样子 —— 他不懂你的上下文。）
```

`name` / `description` 写不写都能用，但**写了下拉里才显示标题**，不写就只有目录名。
目录名就是 skill 的名字，中文英文都行，不能带斜杠或反斜杠。

## 带资源

主文件里引用同目录下的文件，请求时会被**内联**进正文：

```
我的skill/
├── SKILL.md          ← 里面写「见 references/术语表.md」
└── references/
    └── 术语表.md
```

三条护栏，撞上不会报错，但那个文件不会生效：

| 限制 | 值 | 超了会怎样 |
| --- | --- | --- |
| 单个资源文件 | 64 KB | 不展开 |
| 整个包内联 | 256 KB | 后面的不展开 |
| 上传单个文件 | 2 MB | 上传中止（M8-SRV-004） |

没展开的会在正文末尾列出来，让模型知道自己缺什么。

## 硬约束

- **UTF-8，不要 BOM。** GBK 的中文会变乱码，而且不报错 —— 这是最难查的一种。
- **一个目录一个 skill。** 别在 skills 根目录直接丢 .md：老格式能读，但会被当成
  「只有一个文件的包」，以后要加资源就没地方放了。
- **只碰你负责的那一个目录。** 别清理、别重排、别动别人的包。
- **别把 `.git/` 带进来。** 从仓库 clone 来的 skill 记得删掉它 —— 不进资源清单，
  但会让整个包变大，而且对模型没有半点用。
- **不在 SKILL.md 里写绝对路径。** 模型拿不到你的文件系统。

## 两条路进来，结果一样

| 怎么进 | 落在哪 |
| --- | --- |
| 节点上的「上传 Skill」/「上传整个包」 | `m8/data/skills/<名字>/` |
| 直接把目录拷进这个文件夹 | 同上 |

拷进来不用重启 ComfyUI，点节点上的「刷新列表」就能看到。

## 装完怎么验证

在节点的下拉里点「刷新列表」，你的包应该出现在里面。或者直接问后端（端口按你的 ComfyUI 改）：

```bash
curl http://127.0.0.1:8188/m8/skills/list
```

`skills` 数组里该有这个名字，`fileCount` 是文件数，`external` 为 false 表示它在插件自己的目录里。

报 `M8-LLM-011 skill 里没有主文件` = 缺 `SKILL.md`，并且目录里连一个文本文件都没有。

## 换设备会怎样

这个目录的**路径**跟着插件走，插件搬到哪它跟到哪，不用改任何配置。
但**装好的包不在 git 里** —— 重新 clone 或从管理器重装，这里是空的。要搬就整个文件夹拷过去。

（如果你想把技能库放在别处，节点上有「skill 目录」按钮可以加额外路径。额外路径存的是
绝对路径，换设备后会失效，日志会提醒你。）
