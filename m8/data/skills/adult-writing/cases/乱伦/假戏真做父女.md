## 案例：《假戲真做（父女）》（alicesw.tw，作者：狼叔，连载中，已通读全篇共2章）

> 33岁失业父亲为钱接下"兽父强奸女儿"的网络电影，却不知同组女演员是自己15岁的亲女儿，化妆+昏暗灯光下互相没认出，假戏真做破了女儿处，事后将错就错，进而又染指12岁的小女儿。题材=父女乱伦+拍片骗局误会，核心卖点是"假戏真做"的身份错位和家庭日常场景里的禁忌偷情。公司方用合同陷阱+偷拍威胁女学生
4. **误会启动装置**：化妆（眉毛加粗+假发）+昏暗灯光+心理暗示（"腦海里把眼前的身體想象成女兒"）→男主没认出女儿；女儿也没认出爸爸
5. **事后合理化**：认出亲女后内心独白"大错已经铸成，无法挽回，還不如將錯就錯，把這場戲演完"——用既成事实堵死道德退路
6. **二次堕落**：深夜道歉谈心→相拥入睡→清晨被女儿肉体刺激梦遗失控→熟睡奸淫→白天持续奸淫→小女儿主动贴上来（撒娇粘人）→阳台失手破处。每一步都有"环境逼的"和"身体本能"双重借口

### 对话与说话方式
- **男主（爸爸）**：自称"爸爸"，对女儿说话用哄骗+淫笑腔（"爸爸喜歡你啊，讓爸爸弄弄!""茹茹，給爸爸懷個孩子吧…!"）；对邻居小孩小花用体面话掩饰（"我幫蕾蕾按摩呢!很爽很舒服的""她不聽話，被我打了屁股"）；对妻子用日常撒谎（"估計和同學鬧別扭了"）。代表台词："爸爸的肉棒插進我的子宮了!""你媽媽上夜班，不在家，你喊破喉嚨也沒人救你的!"
- **茹茹（大女儿）**：称呼"爸爸"，前期哭喊抗拒（"爸爸，不要插進去，我是你的親女兒茹茹啊!""媽媽!救我!"），后期压低声音怕暴露（"爸爸，快抽出來，媽媽要進來了!"）；代表台词："爸爸，不能射啊！"
- **蕾蕾（小女儿）**：撒娇甜嗓，"爸爸"挂嘴边（"不嘛，爸爸好久沒有抱過我了!""爸爸，有根棍子頂到我的屁股了，幫我拿開它"），被干时只能用嗯嗯呻吟回答
- **第三方声音**：妻子（厨房喊话、门口敲门、钥匙声）、司机大哥（把女儿当女朋友调笑）、邻居小女孩小花（天真问话"你怎麼把蕾蕾弄疼了"）——全部是"差点发现"的警报器角色
- **声线变化线**：茹茹从第一章惨叫反抗（"不要…好痛…"）→第二章压抑低吟（"嗯…嗯…"怕被妈妈听见），音量越来越低、恐惧感越来越强；蕾蕾从天真撒娇→亢奋说不出话→只能呻吟回应
- **语气增强元素**：省略号+感叹号连用（"啊…啊…啊!"）是呻吟标配；破折号少用；对话里大量"!"制造急切感；第三人称场景用"…"转场

### 心理描写
- **挣扎双线**：男主"要是被女兒發現，會被當成獸父吧"的理智警告 vs 硬起的肉棒；射精前"我不能那麼禽獸"的自警 vs 下一秒失控
- **身体诚实**：女儿嘴上喊不要、阴道却分泌大量液体，子宫收缩吮吸龟头——"不受意識控制"的生理反应是堕落的证据
- **自我合理化**：经济压力合理化接活→"将错就错"合理化继续→"她應該很舒服了"合理化在邻居面前的行为
- **堕落心理链**：戒心消失（拍戏尺度大）→接受真强奸（钱）→发现是亲女仍不拔出（怕暴露+大错铸成）→深夜道歉（感情软化女儿）→清晨失控（身体本能）→白天持续奸淫（习惯化）→小女儿主动送上门（顺手推舟）
- **女儿视角心理**：茹茹"一時分不清是夢還是現實"（梦境里男神变爸爸的幻境）；蕾蕾事后"爸爸把我的處女身破了，我該怎麼辦"的懵懂恐慌——被干时沉溺快感、事后清醒自责的两段式

### 场景设计
- **家庭场景**（主战场）：客厅沙发（日常亲昵）、厕所（偷内裤手淫）、女儿房间（反锁/备用钥匙潜入）、厨房（妻子在做饭的威胁源）
- **拍摄场景**：星辰公司办公室（签合同、谈条件、开抽屉亮钱）、拍摄卧室（只开一盏昏暗小灯——误认的关键光线条件）
- **阳台半公开场景**（最出彩）：白天、下半身被墙挡住只露腰以上、邻居小孩小花全程隔空对话围观，男主一边和小花说话一边抽插
- **光线运用**：昏暗光线既是误认的道具，也是偷情的掩护；白天天亮后则靠"妻子马上回来"的紧迫感替代黑暗
- **昼夜双面**：夜间潜入（无声、开锁、怕惊醒）vs 白天奸淫（妻子上班空档、女儿在家人来人往）

### 可复用的套路模板
1. **假戏真做误会模板**：双方各自因不同原因进入同一场景（拍戏/试镜）→伪装+昏暗光线+心理暗示导致互认不出→真刀真枪做→事后发现是至亲→"大错铸成"将错就错。核心钩子：读者全程知情，角色全程不知情
2. **经济困境加码模板**：失业→被迫接活→活儿一步步升级（正常戏→尺度戏→真做→加钱）→每步都"无法拒绝"。给乱伦套上"不得已"的外壳
3. **门外警报模板**：性交进行时插入外部干扰源（妻子敲门/钥匙声/邻居喊话/手机响），角色必须一边忍射一边应付，干扰越近射得越快
4. **半公开遮挡模板**：利用物理遮挡（阳台矮墙、窗帘、桌子）藏住下半身，让第三方在场对话，性行为在正常对话掩护下进行，暴露风险=快感来源
5. **睡梦奸淫模板**：深夜潜入→道歉谈心软化→相拥入睡→清晨被肉体刺激本能失控→趁熟睡插入→醒来时已分不清梦与现实。女儿"梦中性爱"的迷糊状态降低抵抗
6. **双女分配模板**：大女儿先到手（意外+强暴），小女儿随后（主动送上门+巧合破处），两女一"被迫堕落"一"天真不知"，制造差异化
