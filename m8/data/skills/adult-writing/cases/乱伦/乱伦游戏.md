## 案例六：《乱伦游戏》（xbookcn.net Blogger 短篇合集，繁体/老式台式情色文）

> 注意：此篇为**多段故事拼贴合集**，主线是"我"（永德/大伟）的经历，中间套嵌姚芳、素珊各自讲述的情色故事，末段又转入"大伟与数学老师殷小玉"的师生故事。老式港台网文风味，文笔有90年代OCR痕迹。

### 分类标签
- **题材/关系**：兄妹乱伦（妹妹主动引导）+ 换偶群交派对 + 师生恋（数学老师×优等生）+ 养母乱伦 + 女买男妓，多线杂糅
- **视角**：第一人称男性（"我"，兄妹线/派对线/师生线同一个男主）
- **节奏**：多段式短篇串联，每段独立成章，段内慢热铺垫
- **核心风格**：老派台式情色文 + 妹妹主动引导型乱伦 + 比赛化群交 + 欲擒故纵调情

### 体型/身体描写要点

- 阴户特写用**食物/器物比喻**："一个白馒头似的阴户涨卜卜的，中间一道粉红色的桃缝""宛如一个饱满丰肥的小笼包""小之又小的葫瓢"
- 无毛描写（白虎）反复出现："耻部光洁无毛""阴阜光脱脱的，一根阴毛也没有"
- 身材辨识度写法："婉珍是个胖妹子，但外貌甜美……月儿的身材苗条，性格温文……翠花娇小玲珑……兰芝则一副女运动员的样子"（群P中靠特点区分角色）

### 情色描写特点
- **词汇风格**：老式网络情色文用词，介于文雅与直白之间——阳具/肉棒/大阳具/肉棍儿/大家伙/肉茎，小穴/小洞/肉洞/阴户/花心/桃缝，不叫"逼/鸡巴"，带点旧式含蓄
- **拟声词丰富**："浦滋一声""咕啾咕啾""啪然有声""火烧竹林的声响"
- **比喻驱动的感官**：阴蒂"被一个装满了温水的袋包裹着"、阴道"像有拉力坚强的松紧带""像小孩子在吃奶似的吮个不停"
- **快感描写以"酥麻/酸痒/飘走灵魂"为主**："灵魂儿也像飘走了""骨头都松软了""骨软筋酥"
- **动作细节**：写抽插深度（"直捣花心""一插到底，一抽到头"）、体位变换（坐怀吞棍、猴儿上树、龙舟挂鼓、六九、后入）、射精位置（嘴里/阴道/屁股）

### 铺垫手法（三种模板并存）
**A. 妹妹主动引导型（兄妹线）**：
1. 日常亲密无避忌：妹妹穿很少走、冲凉不关门、摸哥哥胸膛
2. 妹妹多性伴侣的暗示：带男同学回家被撞见（兄妹乱伦的"合理性"铺垫——妹妹本来就很开放）
3. 手交突破：妹妹撞见哥哥自慰，主动帮忙（"又不是和你性交，怎么可以叫乱伦呢？"偷换概念）
4. 口交+骑乘：用"只要不射在体内就不算乱伦"的逻辑阶梯
5. 完全越界：派对中妹妹主动求欢，哥哥在妹妹体内射精

**B. 比赛化群交（红衣俱乐部）**：脱衣计时赛 → 口交耐力赛 → 黑人性爱赛 → 肛交加赛 → 持久战决胜 → 赢家配对（把乱交包装成"有规则的游戏"）

**C. 欲擒故纵调情（师生线）**：老师发现作业本上的画像 → 单独约谈 → 男主装悲伤欲走（"我要走了，说不定永远见不到你了"）→ 老师拉住主动献吻 → 改称呼（老师→玉姐→爱妻）→ 逐步升级

### 对话风格
- **妹妹挑逗系**："原来哥哥也在自慰，不如让我来帮你啦！""是不是祇要你不在我身体里射精就不叫乱伦呢？"
- **逻辑偷换系**："又不是和你性交，怎么可以叫乱伦呢？"
- **逗问式调情**（师生线经典）："我们现在在干什么？""做爱！""那个的洞在挨插呢？""我的洞在让你插嘛！"——明知故问逼对方说淫话
- **撒娇报数系**（派对收尾）："你有没有算过出了几次，玩了几个女人呢？"
- **讲故事的插入式对白**："姚芳讲到这里，我问她道……"（用对话自然切换套嵌故事）

### 心理描写
- **哥哥的道德挣扎但快速缴械**："我连忙阻止说道：千万别这样，我们已经是兄妹，不能乱伦呀！"——挣扎只停留一两句，随即被身体快感带过
- **理性化的堕落**："既然已经乱了，为什么不乱个痛快"（妹妹之口，替男主完成心理说服）
- **事后愧疚轻描淡写**："我终于和妹妹做出不该做的事了。"（一句带过，随即被安慰）"有什么该舆不该呢？"（嘉雯用避孕措施消解道德负担）
- **恋母情结暗示**："我自幼缺少母爱，这时躺在一个女人的怀抱里，感觉说不出的温馨和舒适"

### 场景设计
- **家庭别墅**：妹妹房间、哥哥房间（夜归听见怪声→撞见奸情→妹妹闯入）
- **客厅沙发**：换偶派对中妹妹与阿星沙发肉搏、嘉雯被哥哥沙发强上（公共空间+旁观者）
- **狂欢别墅大厅**：男女分开冲洗、集体评论身材、"十二点前一对一、十二点后狂欢"的规则设定
- **浴室/温泉**：素珊故事的主场景，水的触感写实（"淫水与浴缸的水混成一体"）
- **学校宿舍/教室**：师生禁忌场景，"怕山民回来"的时间紧迫感
- **"讲故事"套嵌场景**：派对做爱间隙，女方讲自己的经历，把新场景用口述引入

### 可复用的套路模板
- **"妹妹主动引导"乱伦模板**：日常无避忌 → 撞见女方多性伴侣 → 被抓自慰 → 手交 → "不算乱伦"逻辑阶梯 → 口交/骑乘 → 完全越界

- **"比赛化群交"模板**：脱衣计时赛 → 口交耐力赛 → 异种族/大尺寸挑战赛 → 肛交加赛 → 持久战决胜 → 赢家结成伴侣（乱交游戏化消解羞耻感）

- **"群P角色辨识"写法**：群交场面用一句身材/毛发/性格特征给每个女角贴标签，避免读者混乱
