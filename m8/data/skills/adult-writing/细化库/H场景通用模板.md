# H场景通用模板（九段式骨架 + 10变体 + 三走向，2026-08-12 通用版）

> 以"男厕所·尿池伪娘"场景为样本提炼。**固定的是骨架，可变的是走向和进入方式**——不是所有场景都走"借口接近→触碰→言语升级"，也不是所有场景都走堕落线。按场景类型选变体，按故事基调选走向。弹选项始终按「选项=主角台词」+主视觉联动。
> **定位（用户确认）**：这是**通用模板**，不是某个题材专用——按用户喜好定制过，但**不绑定堕落**。堕落线只是走向之一，纯暴力强奸、轮奸也是独立走向。

## 📋 九段式骨架（固定，每场都有的阶段）

```
① 设定 → ② 开场（日常感） → ③ 进入方式（变体，见下）
→ ④ 身体被控 → ⑤ 交锋（言语/沉默） → ⑥ 弹选去向
→ ⑦ 主玩法（弹选） → ⑧ 射精（弹选） → ⑨ 收尾（当场完）
```

**说明**：③进入方式是变体区，④⑤按变体配合（有些变体没有言语交锋，直接沉默强暴），⑥⑦⑧弹选项通用，⑨收尾通用。

## 🎯 三走向（2026-08-12 用户确认：模板去堕落绑定）

> **先定走向，再写场景**。走向决定④⑤和主动程度的写法。同一套骨架，三种走向都能套。

| 走向 | 定义 | ④⑤写法 | 主动程度 | 适用 |
|---|---|---|---|---|
| **A. 堕落线** | 强暴→身体诚实→接受→主动求欢（或驯化成奴），有心理变化弧线 | 被控住→停不下来→自己想要（随堕落递进） | 前期被动→中期半推半就→后期主动 | 长故事/乱伦/养成 |
| **B. 纯暴力线** | 从头到尾就是暴力/强迫/物化，**无堕落弧线**——施暴者一直暴力，受方一直被迫，没有"接受" | 从头到尾**被控住**（一直物理压制，不松） | 全程被动（哭/挣扎/反抗，从不主动） | 单场强暴/短篇/猎奇向 |
| **C. 纯轮奸线** | 多人暴力轮奸，受方是**公用物**，**无个人心理线**——焦点在轮换/交接/群P | 从头到尾**被控住**（被多人按住，换人时也不松） | 全程被迫（哭到失声/麻木） | 轮奸群P/公用肉便器 |

**走向选择规则**：
1. **开局确认第6项堕落类型**（快乐堕落/驯化成奴/纯爱毁灭）选了 → 走A堕落线
2. **用户没要堕落，只要暴力/轮奸** → 走B/C线，**不套堕落三阶段**——被控三态里只用"被控住"，"停不下来/自己想要"不用
3. **同一场景不同走向写法完全不同**：堕落线"他哭但身体诚实地硬了"，然后一步步走向接受、主动；纯暴力线可以写"他哭着被操硬了、被操到流水"这种**被迫的生理反应**——身体诚实但心理始终抗拒（厌恶/恐惧/屈辱/绝望），反差带来的是**更深的羞耻和绝望**，不是堕落快感。暴力线只写"不情愿的那种、被迫有感觉"，身体反应是**不受控制的、被迫的**，绝不走向"接受→主动"。详见下方"暴力线的被迫生理反应"区块

**暴力线的被迫生理反应（2026-08-12 用户确认，B/C线通用）**：

纯暴力线/纯轮奸线**可以写受方快感**，但只写"不情愿的那种、被迫有感觉"——**身体诚实但心理抗拒**：

- **受方心理**：厌恶/恐惧/屈辱/绝望，一直不情愿，从开场到结束都不松动
- **受方身体**：可以出现流水/湿润/勃起/被操到高潮等生理反应，全是**被迫的、不受控制的**
- **核心写法**：心理抗拒和身体反应的反差——"明明不想，身体却……""被强奸却还……"——这种反差带来的是**更深的羞耻和绝望**，不是堕落快感
- **与堕落线的区别**：堕落线"身体诚实→接受→主动"；暴力线"身体被迫反应→心理始终抗拒→羞耻绝望加深"，**不走向主动**
- **案例素材**：详见 `强奸场景模板.md` 和 `轮奸场景模板.md` 的"受方反应"部分

## 🎯 弹选节奏总规则（2026-08-12 用户逐条确认）

| 环节 | 规则 |
|---|---|
| **弹选次数** | **看紧张度**——场景越紧张越要多弹（紧张时用户需要选项掌控节奏），平淡场景少弹 |
| **⑥ 弹选去向** | **有则弹 + 做大分歧**——有"去哪"选择才弹；选项要做成**大分歧**（周末去泳池/在家呆着/去练舞→引出完全不同的后续事件线），不是"在这还是去里面"这种微调 |
| **⑦ 主玩法** | **弹候选玩法（可多选）**——玩法库要全（见下方主玩法库），**前期也可能有强奸/轮奸/颜射**，不是前期只能单选；按场景预配候选，弹选时看紧张度决定弹几个 |
| **⑧ 射精** | 每次弹（内射/外射/颜射/口爆/射身/射裙上等） |
| **服装状态线** | **关键点弹**——撕不撕裙子/射不射裙上/穿不穿回去等关键时刻弹，平时随过程自然变（完整→皱→脏） |
| **⑨ 收尾后续** | **长篇才弹 + 看走向**——堕落线前期弹（威胁保密/约定下次/日常化，关系未定），后期不弹（已成习惯）；纯暴力线弹（威胁/抛下/下一次还会来）；轮奸线弹（被丢弃/被传开/明天还来）。短场景不弹 |

## 🔀 进入方式变体（③④⑤的组合，10种，按场景选）

**被控三态（用户确认，按走向选用）**：
- **被控住** = 逃不掉（物理压制：按墙/按地/人墙/捂嘴；或心理不敢逃：把柄/威胁/被照顾名义钉住）——**三走向通用**（纯暴力/轮奸线全程用这个）
- **停不下来** = 生理无法中断（尿一半/药效发作/意识模糊/高潮中）——**堕落线前期/中期用**
- **自己想要** = 后期堕落深了，主动贴上来（自己缠上去、求着要、自己摆好姿势）——**堕落线后期专用，纯暴力/轮奸线禁用**

### 变体A：日常渐进（借口接近型）
- **适用**：家中/教室/辅导/照顾场景（乱伦慢热、信任型攻方）
- **③ 进入**：借日常动作接近（辅导/擦药/递东西）→ 手"不小心"碰到 → 停留变久
- **④ 被控**：**被控住**——他还没反应过来，已经被"照顾"的名义搂住/按住，愣住不敢动
- **⑤ 交锋**：言语温和包装（"帮你擦擦""检查一下"）vs 他隐约觉得不对
- **例子**：辅导功课→手从肩滑到腰→"写作业别乱动"

### 变体B：直接强暴（暴力突破型）
- **适用**：陌生人/堵路/厕所/暗处场景（无铺垫直接上）
- **③ 进入**：直接扑上来/捂住嘴拖走/按倒——没有试探，开场即暴力
- **④ 被控**：**被控住**——力气悬殊被压制（按墙上/按地上/捂嘴）
- **⑤ 交锋**：他挣扎喊叫→被捂嘴/威胁（"喊就弄死你"）；或全程沉默（只剩动作和喘息）
- **例子**：放学路上被拖进小巷→按在墙上→撕裙子

### 变体C：睡奸/无防备（熟睡型）
- **适用**：深夜家中/床上/浴缸（他睡着了或半醒）
- **③ 进入**：他熟睡/半梦半醒，攻方摸进被窝/浴室
- **④ 被控**：**停不下来**——意识模糊，想醒醒不过来（被摸到有反应才惊醒）
- **⑤ 交锋**：他以为做梦→"不要…嗯…"→惊醒时已经来不及
- **例子**：半夜被摸醒，以为是梦，身体却已经有了反应

### 变体D：迷奸/下药（无意识型）
- **适用**：饮料/酒/药（他喝了被下药的东西）
- **③ 进入**：他喝了东西→头晕/发软→意识模糊
- **④ 被控**：**停不下来**——浑身无力，想动动不了（药效）
- **⑤ 交锋**：他含糊地说"头晕"→被扶住→"我帮你躺会儿"→无力反抗
- **例子**：生日聚会喝了果汁→越来越晕→被扶进房间

### 变体E：言语调戏渐进（嘴炮型，男厕所那个）
- **适用**：公共场合/厕所在场有人（尿池/更衣室/电车）
- **③ 进入**：攻方先言语调戏（"小妹妹""穿这样给谁看"）→ 边说话边靠近
- **④ 被控**：**停不下来**——他僵住/尿到一半停不下来（生理上无法中断）
- **⑤ 交锋**：调戏→点破（"我知道你是男的"）→威胁（"别出声"）分级上
- **例子**：尿池边，"尿你的，别停，我就看看"

### 变体F：胁迫/把柄（威胁型）
- **适用**：伪娘秘密/女装/照片被拿捏
- **③ 进入**：攻方亮把柄（"穿这样被学校知道就完了"）→ 他被迫配合
- **④ 被控**：**被控住**——心理不敢逃（怕曝光），身体配合
- **⑤ 交锋**：他求"别告诉别人"→攻方"听话就不说"→半推半就
- **例子**："你女装的视频在我这，过来。"

### 变体G：围观起哄（群体压力型）
- **适用**：被围观/多人/公开场景
- **③ 进入**：周围人起哄（"脱啊""让他试试"）→ 群体压力推着走
- **④ 被控**：**被控住**——被多人围着，逃不出去（人墙）
- **⑤ 交锋**：他求饶→起哄声更大→半推半就被推着进行
- **例子**：更衣室被几个男生围住，"都看到了，别装了"

### 变体H：误认/错位（身份误会型）
- **适用**：伪娘被当女孩/性别错位
- **③ 进入**：攻方以为他是女孩（搭讪/调戏）→ 他不敢说破（怕暴露）
- **④ 被控**：被当作女孩带走/按住→他不敢澄清（一澄清就暴露秘密）
- **⑤ 交锋**：他小声"我是男的"→ **弹选决定（用户确认）：两种都备好**——A. 更兴奋型（有素材）"男的？那更好"；B. 吃惊型（只有推理版）吃惊→愣住→犹豫→被欲望拉回去
- **例子**：被当成漂亮女生搭讪→拉进暗处→"我其实是男的…"→（弹选：更兴奋/吃惊）

### 变体I：药效主动（催情型，用户确认补）
- **适用**：下药/灌酒后药效发作（他主动贴上来）
- **③ 进入**：被下药/被灌酒→药效发作→身体燥热→主动贴上去
- **④ 被控**：**停不下来**——被药效控住（身体自己动，理智压不住）
- **⑤ 交锋**：嘴上说"我不要"身体却缠上去（药效催情的主动，比D更主动）
- **例子**：喝了加了料的饮料→越来越热→自己往他身上蹭→"好热…"

### 变体J：救星反转（被救反操型，用户确认补）
- **适用**：被"救"出来，结果被救他的人操
- **③ 进入**：他被欺负/被困→有人来"救"→救他的人反而动手
- **④ 被控**：**被控住**——刚以为得救，放松警惕时被控住（信任被利用）
- **⑤ 交锋**："我救了你，你该报答我"→从感恩到被迫（信任崩塌更狠）
- **例子**：被坏人追→被路人"救"→"别怕，我带你走"→带到没人的地方反被按倒
- **📎 详见**：`救星反转变体细化.md`（五段式结构/攻方类型/堕落三阶段/弹选点/场景卡）

## 🎲 变体组合规则

1. **一个场景选1-2个变体组合**（如：E言语调戏→B直接强暴；或C睡奸→F胁迫；或I药效主动→J救星反转）
2. **被控三态对应表**（按变体+堕落阶段选④怎么写）：
   - **被控住**（逃不掉：物理/心理）→ A日常渐进 / B直接强暴 / F胁迫 / G围观起哄 / J救星反转
   - **停不下来**（生理中断）→ C睡奸 / D迷奸 / E言语调戏 / I药效主动
   - **自己想要**（后期主动）→ 不限定变体，堕落后期通用（前期是被控住/停不下来的变体，后期同一场景重演时切换成"自己想要"）
3. **⑥⑦⑧弹选项通用**——不管哪个变体进来，到去向/主玩法/射精都是弹选项
4. **场景类型→推荐变体**：
   - 厕所/暗处/陌生人 → B直接强暴 / E言语调戏
   - 家中/照顾/辅导 → A日常渐进 / C睡奸
   - 伪娘秘密 → F胁迫 / H误认
   - 公共/多人 → G围观起哄 / E言语调戏
   - 下药/酒局 → D迷奸 / I药效主动
   - 被救场景 → J救星反转

## 📋 场景卡示例（套用变体B：深夜小巷·直接强暴）

**① 设定**：放学夜路，他穿水手服被当女孩，陌生人尾随
**② 开场**：他正常走路回家，路灯忽明忽暗
**③ 进入（变体B）**：突然被从后面捂住嘴，拖进小巷——没有试探，直接暴力
**④ 被控（被控住）**：被按在墙上，力气悬殊，他挣不开
**⑤ 交锋**：挣扎想喊→被捂嘴，男人低吼"喊就弄死你"；他眼泪掉下来，不敢出声
**⑥ 弹选去向**（有则弹，做大分歧）：A. 就地解决 B. 拖到更里面的废弃仓库 C. 拽着他回家——**三条线后续完全不同**（就地=速战速决/仓库=长时间折磨/回家=可能被更多人撞见）
**⑦ 主玩法**（弹候选，可多选）：口交 / 后入 / 肛交 / 掐脖 / 颜射
**⑧ 射精**（弹选）：内射 / 口爆 / 颜射 / 射身上
**⑨ 收尾**：他瘫在墙根，裙子撕了，白丝脏了——【场景完】（长篇则弹后续：威胁保密/约定下次/日常化）

## 使用规则

1. **骨架固定（九段），进入方式多变体（10种）**——不固化死，变体可自由混搭、改造、创新（最高原则）
2. 写H场景前：选地点→选变体（1-2个）→套骨架→按弹选节奏规则弹选项
3. **弹选次数看紧张度**：场景越紧张弹越多次（去向/玩法/射精/服装关键点全弹），平淡场景少弹
4. **去向弹选要做大分歧**：选项引出不同后续事件线（去泳池/在家/去练舞），不是位置微调
5. 弹选项始终按「选项=主角台词」+主视觉联动
6. 服装状态线：平时自然变，撕不撕/穿不穿回去等关键点弹选
7. 收尾后续：长篇前期弹（威胁/约定/日常化），后期不弹（已成习惯）
