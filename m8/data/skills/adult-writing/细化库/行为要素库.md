## 附：场合维度（2026-08-14 新增，行为×场合四档）

## 一、场合档位定义（4档）

| 档位 | 缩写 | 含义 | 例子 |
|---|---|---|---|
| 私下 | 私 | 独处/一对一，无第三者在场，隔音好不会被发现 | 家里锁门的房间、深夜教室、办公室里只剩两个人 |
| 公开 | 公 | 公共/半公共场合，可能被人看到或听到 | 办公室门没锁、走廊、客厅有家人、教室、电车 |
| 多人面前 | 众 | 同场多人目击，多人参与或旁观 | 轮奸同场、朋友在旁看、排队轮候 |
| 被围观时 | 围 | 公开场所被陌生人/人群围观起哄 | 车站、街头、操场、直播观众 |

**补充说明**：
- "隔音差/门没锁/客厅有人"这种半公开状态，按"公"处理就行，不用单独开一档，不然档位太多查起来累。
- "众"和"围"的区别：众是场里的人（参与者/熟人），围是场外的人群（陌生人观众）。旁观者库的"起哄"对应围，"同场参与者"对应众。

**混合写法**（给两态和链式词条用）：
- `A↔B`：两态。同一个行为在两种场合表现完全不同，写作时按场合选版。
- `A→B`：链式。行为从一种场合延伸到另一种，常是一个段落的推进线。

## 二、受场合影响最大的行为（重点三组+案例）

### 1. 服从行为（受影响最大）

私下服从和公开服从是两种戏。私下服从可以偷偷做、磨蹭做、没人看见；公开服从是被命令当众做，每一步都有人看着，羞耻和堕落感完全不是一个量级。

- 私下版：三"被逼服从动作"（不情不愿地脱内裤，踏入深渊）、三"反复确认"、三"小声嘟囔反抗"——软抵抗，动作可以慢，脸可以不红。
- 公开版：十二"公开服从行为"整类——遥控走路、路人目击下继续、真空外出、车站出道，全是公开场合命令型露出，慌不慌看堕落程度。
- 案例：同一个"跪着"的命令。家里私下跪=日常调教，做完就完了；车站命令跪着=路人看着，跪的每一秒都是羞耻，围观的人越多越走不动（十二类核心链：被遥控→路人目击→车站出道）。

### 2. 求欢行为（受影响最大）

私下求欢是撒娇，公开求欢是自荐发骚。台词可以一个字不改，场合变了意味全变。

- 私下版：十一"主动索求"（"呐…给我嘛…"炉姦12 ch3）、"服务承诺"——一对一，缠着攻方要。
- 公开版：同一句"给我嘛"放到多人面前说=当众索求，围观者会接话、起哄、排队。配信主动索求（贝尔ちゃん"萝莉控的变态们都勃起了吗"）本身就是对着观众要。
- 案例：ひなた私下说"给我嘛"是撒娇，缠着叔叔不放；同样这句话换成在几个人面前说，变成当众自荐——"谁先来"的意味。台词没改，场合把它从撒娇变成了发骚。

### 3. 走光行为（受影响最大）

走光行为整个就是"场合探测"行为。走光确认链的每一步都在回答一个问题：有没有人在看。

- 九"走光确认行为"全链：弯腰提袜触发走光→猛然意识到→站起来回头确认→确认结果。没人看到=虚惊一场，被人看到=羞耻当场拉满。
- 案例：踏入深渊的提袜走光——"我站起来，回头，期待没有人看到"，结果"事与愿违，两个男生正站在我身后"。同样的走光，没人的时候只是凉风，有人的时候是被抓包。这链子每步都是场合问题。
- 主动版（围）：九"主动露出"（炉姦12 ch3ひなた拉开兜裆布摇屁股）——场合里有人才叫露出，没人的露出没有意义。

### 4. 其他受场合影响大的行为

- **被逼叫 vs 被逼忍**（一）：私下攻方逼"叫啊骚货"（琪琪办公室）；公开场合命令方向反过来——捂住嘴命令"别出声，被听到就完了"。同一个攻方，场合变了命令跟着变。
- **忍耐不出声/呼吸层级递进**（一）：私下忍=性格使然；公开场合忍=怕被听到。公开戏里受方不能叫的时候，呼吸递进是唯一的状态出口。
- **呼救升级链**（八）：呼救就是喊给更多人听的，公开场合（有围观者）才能喊到"妈妈救命"；私下呼救没人听见，喊到嗓子哑也没用，最后只剩认命（炉姦12 ch8三沙的哭求升级链：求饶→放弃）。
- **被灌满忍不住叫**（五）：私下=忍到射精才叫的爽点（琪琪"啊~她忍不住呻吟了出来"）；被围观时叫=当众暴露快感，围观者会起哄"她叫了"。
- **事后擦现场**（六）：被撞见/可能被撞见时擦得更慌，擦现场这个动作本身就怕被人发现痕迹。

## 四、场合标注方案（三种方案对比）

### 方案A：全表加列，每行必填

14个大类所有词条都标一个场合值。
- 优点：查词时每行都有，不用猜。
- 缺点：大部分词条是"不限"，每行都填等于填一大堆废话，表格变宽变乱，改动量也大。

### 方案B：全表加列，只标受影响词条，留空=不限（推荐）

14个大类统一加"场合"列，但只有受场合影响的词条填值，不受影响的留空。
- 优点：表格统一（每个类都有这一列，查词不用记哪个类有哪个没有）；重点突出（一列扫过去就看到哪些词条挑场合）。
- 缺点：需要记住"留空=不限"这个约定，写进使用规则就行。

### 方案C：只在受影响大的大类加列

## 五、逐类标注清单（哪些词条标什么，草稿）

> 标注格式：词条名（所在类）→ 场合值。没列到的词条=不限。

**一、被操时行为**（标4条）
- 被逼叫 → 私↔公（两态：私下逼叫，公开场合命令反过来变成逼忍）
- 忍耐不出声 → 公/围（公开场合必用：私下忍是性格，公开忍是怕被听到）
- 呼吸层级递进 → 公/围（出声被禁止时唯一的出口，公开戏高频）
- 失守泄密 → 围（当众说出秘密=羞辱加深）
- 不标：被肏着说话、被肏着小声嘟囔、闭眼想象、言行矛盾

**二、被摸时行为**（标2条）
- 噤声压抑 → 公/众（全库最典型的场合敏感词条：有外人才噤声，没外人就能出声。炉姦12 ch5母亲在场被摸的场景就是场合戏）
- 睡梦承接 → 私（睡奸只能私下）
- 不标：出声说话、吼叫反抗、起反应坦白、扭动挣脱、隐忍不动、僵硬配合、惊恐乳硬、内心祷告

**三、被控/被逼时行为**（标3条）
- 被围观低头回避 → 公/围（行为本身就是被围观时的反应，踏入深渊"低下头攥着书包"）
- 排队轮候 → 众（制度性多人场合，炉姦12 ch11精液值日生）
- 被堵嘴闷声 → 公（公开场合堵嘴=切断呼救，围观者看着）
- 不标：反复确认、小声嘟囔、被逼服从动作、敷衍回答、遮掩转移话题、被控住挣扎、被逼哭求、底线谈判

**四、被插入时身体反应**（标1条）
- 单音断裂 → 公/围（憋着不出声时漏出来的单音，公开场合更贴切）
- 不标：疼到收缩、被顶疼形容、懵懂提问、推倒叫痛、疼哭、强行撑开物理感、张开承接、湿透自动张开、心理割裂

**五、被射入时反应**（标2条）
- 被灌满忍不住叫 → 私↔围（两态：私下=忍到射才叫的爽点；被围观时叫=当众暴露快感，会被起哄）
- 意犹未尽确认 → 私（独处撒娇；当众要=更深堕落，需要上下文，不默认）
- 不标：身体承接、瘫软余态、懵懂追问、拟声复述、冲走厌恶、灌满陶醉、物化认同、射后顶挤

**六、事后收拾行为**（标2条）
- 第一反应擦现场 → 公（可能被撞见时擦得更慌，擦现场本身就怕留痕迹）
- 满精日常 → 私→公（链式：私下被灌满→穿着满精内衣走进公开场合，痕迹带出门）
- 不标：用行动道歉、事后录像确认、尿失禁道歉

**七、旁观者介入行为**（标4条）
- 门缝偷窥 → 公（隔门/隔墙偷看，半公开旁观）
- 隔门偷听 → 公（同上，いじめっ子 h7/h10偷听线）
- 围观评点、围观不阻止 → 围（群体围观时，炉姦12 ch8村民评头论足）
- 被迫观看 → 围（被按着当观众）
- 不标：苦笑、敲门质问、介入护住、隔门察觉情绪、勃起被点破

**八、连贯反抗动作链**（标2条）
- 呼救升级链 → 围/公（呼救就是喊给更多人听的；私下呼救没人听见，只剩绝望）
- 呼救被闷 → 围（公开场合把呼救掐断，围观者看着，比私下堵嘴更绝望）
- 不标：表情凶狠→推→踢→骂链、浑身发软态度强硬、带哭腔赶人、哭求升级链、边哭边骂、抗拒单音断裂、口拒身诚、拒绝挡手

**九、走光确认行为**（标7条，本类整体是场合探测行为）
- 弯腰触发、猛然意识到、站起来回头确认、确认失败 → 公（在可能有人的场合探测）
- 留意目光、真空确认、加速行走 → 公
- 脸红拉裙 → 公
- 主动露出 → 围（场合里有人才叫露出）
- 睡着被动走光 → 私（睡奸场合）
- 不标：脱衣分步僵住（私下公开都有）

**十、洗脑复读行为**（标1条）
- 被逼学舌 → 私↔围（两态：私下复述=养成；当众复述=羞辱强化，内容一样，听众变了）
- 不标：点头复述、占有宣言+懵懂反问、复述时委屈、自我物化宣言

**十一、主动求欢行为**（标2条）
- 主动索求 → 私↔众（两态：私下=撒娇"给我嘛"；多人面前=当众自荐，围观者会接话）
- 配信主动索求 → 围（线上被围观，虚拟场合）
- 不标：营业撒娇、服务承诺

**十二、公开服从行为**（标1条-整类）
- 全类4条（遥控走路、路人目击下继续、车站出道、真空外出）→ 公/围（本类定义就是公开场合命令型露出，场合固定，标注只是明示）

**十三、气味调教行为**（标2条）
- 被嗅闻、被精液涂抹、被嗅气味训练 → 私（气味线基本私下调教）
- 不标：气味渐变、气味上瘾（心里状态不挑场合）

**十四、驯服后主动服务行为**（标1条）
- 展示身体 → 围（直播/当众展示，いじめっ子 h17轮奸直播）
- 不标：主动请求服务、主动张腿、求内射、回家羞耻问候（一对一/回家场合，本身就在私下）

## 七、场合×行为写作规律（6条）

1. **公开场合，受方不能出声。** 噤声压抑、忍耐不出声、呼吸层级递进、被堵嘴闷声都是"不能出声"系的。公开戏的张力在憋，不在叫。写公开戏先想：她现在敢不敢出声。
2. **服从行为在公开场合更羞辱。** 同一条服从行为，听众越多越羞耻。当众服从比私下服从难受得多，这是十二类的核心，也是"场合越公开堕落越深"的来源。
3. **走光行为靠场合吃饭。** 走光确认链每一步都在探测"有没有人看"。被目击=羞耻高潮，没人看到=虚惊一场。写走光戏先定场合，再走确认链。
4. **生理反应不挑场合。** 疼、收缩、瘫软、被灌满的身体承接哪都能写。写公开戏时，砍掉出声和大动作，保留"忍着"和生理反应，就是正确的公开版。
5. **被围观时和旁观者库配套写。** 受方被围观时的行为+他人表现库的围观起哄、点评身体一起用。观众的反应就是场合的注脚——受方越忍，围观者越起哄。
6. **场合两态词条写对照。** 同一行为私下写放开版（能叫能动），公开写收着版（忍、压、偷瞄），两版对照着写张力最大。比如被逼叫：私下"叫啊"vs公开"别出声"，同一个攻方同一场戏的两条路。
