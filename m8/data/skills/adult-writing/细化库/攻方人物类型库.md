# 攻方人物类型库（轻量简版，2026-08-13 新建）

> **定位**：本库是攻方**身份类型**的索引——写"是谁在动手、他属于哪一类、这类人怎么压迫"。
> 与攻方反应库互补：**反应库写"怎么动"（生理/心理/语言），本库写"是谁"（身份/动机/压迫方式）**。
> 写作流程：先在本库定攻方类型 → 再查 男性施暴方反应库_细化版.md / 女性施暴方反应库_细化版.md 写具体动作反应。

> **开局对接指引（interactive-novel 开局第6/7问）**：开局第6问家庭情况决定第7问攻方类型选择——**有家人**（父母/亲戚同住）→ 攻方优先家族型（亲父/继父/兄长/祖父，见3）或单攻·熟人型（邻居/亲戚借住，见1），第7问给家人捏人时按这两类定身份；**没家人**（独居/父母不在）→ 攻方可选单攻·陌生人型（话术诱导/物理压制，见2）、集团型（见4）、制度型（见7）、女攻型（见6）、兽攻型（狗线，见5），且第7问不捏攻方、细节留到H前再讨论——H前弹点时回查本库定类型，再查攻方反应库写动作。类型可叠加（见使用规则2）。

## 二、各类型要点（2-4行）

### 1. 单攻·熟人型（老师/邻居/亲戚）
- **动机**：长期觊觎+身份便利，靠日常接触慢慢越界；老师用"教育/辅导"当幌子，亲戚用"照顾/亲情"当幌子。
- **语言风格**：伪善亲昵（"绫乃酱真是个好孩子呢"）→ 洗脑式命令（"从现在开始你就是我们的手下了"），常用职业身份压人（"不听话就处分/告诉家长"）。
- **压迫方式**：不靠暴力，靠关系绑架——受方顾忌名声、前程、亲情不敢声张，越界点藏在日常里。
- **代表台词**：「呼，一直都想要你的内裤呢。这样我就可以更好地自慰了。」（君边）

### 2. 单攻·陌生人型（流浪汉/痴汉）
- **动机**：一次性猎物心态，无后续责任，吃干抹净就走；分两路：**话术诱导型**（哄骗、包装、食言）和**物理压制型**（体格碾压、直接动手）。
- **语言风格**：话术型自称"教你/帮你"，把性包装成"胜负/服务/成长"（「セックス勝負はこいつを使ってするもんなんだよ」）；压制型粗俗羞辱（「こんな具合のいいメスガキマンコッ、我慢出来るかよ」）。
- **压迫方式**：话术型=骗入局+食言不认账（「大人ってのは、みんな嘘つきなんだよ」）；压制型=堵嘴按手、体力差硬来；痴汉型=公共场所环境掩护（电车/公车），趁拥挤下手、围观者不敢管。
- **代表台词**：「お前がスケベでエッチな女の子だって認めるのか？」（滑川，标签逼认）
- **诱拐犯三连**（对幼童/低龄受方专用，Yuka漫画）：①**温柔瓦解戒备**（期1）——"别害怕哦 我会陪你一起玩的""8岁就这么懂事了啊"，用夸奖和温柔话术瓦解孩子戒备（Yuka第0-2页）；②**洗脑式说教**（期2-3）——"只要做舒服的事就够了""家人朋友什么的全都舍弃掉"，性行为后用说教洗脑让孩子接受现状（Yuka第8-9页）；③**威胁收尾**（期1）——"你父母也不希望女儿作为公共便女被找到吧"，用威胁堵死求救之路（Yuka第24页）。链条：先哄→再洗→后威胁，一步步收网。

### 3. 家族型（亲父/继父/兄长/祖父）
- **动机**：独占欲（"女儿是我的"）、复仇转移（妻子背叛→恨转移到女儿身上）、养成癖（从小养大当私有物）。部分有绿帽癖/共犯倾向（把女儿送人换利益）。
- **语言风格**：极端的两面——日常还是"爸爸/哥哥"的称呼，越界时用伦理话术正当化（「女はみんなこの穴を空けて大人になるんだからな」）；占有宣言（「お前は俺の女だ」）。
- **压迫方式**：家庭空间=封闭牢笼，靠经济/亲情/名声三重绑架；从小养成则先洗脑"这是爱/这是惩罚"，让受方主动配合（「┬はおじちゃんの恋人です」复读）。
- **代表台词**：「ああ、そうだ。お前の処女を破らせてもらった。薫子っ、処女喪失おめでとう！」（慎哉）

### 4. 集团型（霸凌集团/轮奸集团/全镇阴谋/痴汉组织）
- **动机**：群体壮胆+征服欲+服从测试；有明确分工——**首领主导**（下命令、定规则）、**打手暴力**（动手、压制）、**军师策略**（想道具、想玩法）；轮奸集团还带"换班制/排队制"让压迫日常化。
- **语言风格**：首领命令式（「从现在开始你就是我们的手下了」）、打手粗暴（「喂，快脱光衣服吧！」）、军师阴阳怪气（「女人都是笨蛋嘛」）；全镇阴谋型用系统化台词（「この町の桃源郷システムから逃げ出そうとしたり、世間に暴こうとする女がたまにいてな」）。
- **压迫方式**：人数压制（一个按住一个上），轮流上=受方失去反抗窗口；制度化（每天列队、轮班表）让受方习惯成自然；全镇型用药物/病毒+共犯网（校长、老师、父亲全是网的一部分）让受方无处可逃。
- **代表台词**：「お前達が、そう言うならいいだろう。いいね、千佳子ちゃん」（面接官，制度化使役）

### 5. 兽攻型（狗）
- **动机**：兽性本能（发情/交尾/种付け/领地标记），不是"恶"，是纯粹的占有欲——反而因为没有人类道德，压迫更彻底。
- **语言风格**：无语言，全靠行为语言（嗅/爬跨/舔/施錠/精液标记）；受方被逼从"人话"退化到学狗叫（「わ、わん……♡」）。
- **压迫方式**：体格差压制→快感植入（身体被改造为"适合它的形状"）→日常化骑乘→主动献身（受方自己解开项圈、放弃主人资格）。
- **代表台词**：「主人の資格を捨てます……♡」（受方被驯到主动说，狗线终点）

### 6. 女攻型（简列，详情看女施暴方库）
- **动机**：支配欲、调教欲、嫉妒（把受方调教成自己的宠物/牝犬）。
- **语言风格**：命令式+羞辱式，用"调教成果"当谈资（「なかなか優秀な牝犬じゃないか」）；京都腔/敬语反差（悠里的"どす"）。
- **压迫方式**：道具调教、精神操控（毒/药物）、社交压制（让受方沦为公用物被围观）。
- **代表台词**：「気安く呼ぶな、牝犬」（rei800b，称呼剥夺）
- **注意**：女攻型只是索引，具体生理/心理/语言反应全在 `女性施暴方反应库_细化版.md`，不在这里重复。

### 7. 制度型（班级制度/设施/公司债务）
- **动机**：**攻方不是某个人，是制度本身**——个人只是制度的执行者/受益者。压迫来自"大家都默认这样"。
- **语言风格**：公事公办口吻（「順番待ってるんだからとっととやってくれって」），把性服务说成"值日/任务/还债"（「ザーメン係初めてなんだから、処女だろ」）。
- **压迫方式**：全班/全设施/全公司一起执行，个人想反抗=对抗整个集体；债务/收养/入学成了合法化的枷锁。
- **代表台词**：「一学期ザーメン係だった小童谷みたいにビラビラしてないな」（同学，把制度当常识）

8. 小恶魔·萝莉支配型（萝莉当攻，成年受方）
- **动机**：纯粹享受支配快感，把受方当玩具/狗；天真外表是最大武器——"小孩子不懂"的伪装让受方无从反抗（受方是成人更羞耻：被小孩子支配）。

## 四、使用规则

1. **先定类型再写反应**：写攻方前先查本库定"他是哪一类"，同一类攻方有统一的动机/语言/压迫逻辑，反应库只写动作细节——两者互补不重复。
2. **类型可叠加**：一个攻方可同时占多类（全镇阴谋的校长=熟人型+制度型；雇佣流浪汉的父亲=家族型+指挥集团）。叠加时以最核心的那类写语言，其他类补压迫方式。
3. **引用关系**：
   - 攻方生理/心理/语言反应 → `男性施暴方反应库_细化版.md`（男攻）/ `女性施暴方反应库_细化版.md`（女攻）
   - 攻方辱骂词 → `辱骂要素库.md`；攻方骚话逼问 → `骚话淫语要素库.md`；攻方表情 → `表情神态要素库.md`
   - 攻方身份→受方关系 → 本库三节矩阵
   - 群交/轮奸场景骨架 → `轮奸场景模板.md`（制度型/集团型必查）
4. **gal素材对照**：需要具体攻方台词例句，回查对应提炼文档（E:\TOOLS\mtool\TRANSLATED\町ぐるみの罠_提炼.md 等，各角色有男侧台词节）。
5. **轻量简版**：本库只做索引和类型区分，不追求例句全量——例句只留每类一条代表性台词，其余到反应库和gal文档里找。

## 附：场合施压（2026-08-14 新增，攻方利用场合施压）

## 一、场合二分总览

| 维度 | 私下场合 | 公开场合 |
|---|---|---|
| 功能 | 建立控制：调教、开发、立规矩、兑现威胁 | 巩固控制：暗示所有权、展示成果、把旁观者变成共犯 |
| 攻方面孔 | 露出真面目（变态/粗暴/占有者） | 维持人设（绅士/长辈/老师/父亲） |
| 受方处境 | 单独面对，无处可逃，空间=封闭牢笼 | 周围有人，但没人会帮她（共犯网/围观不敢管/被包装成正当） |
| 典型舞台 | 指导室、房间、保健室、教室后门、家 | 教室、朝礼台、餐厅、家庭聚餐、电车、办公室 |
| 压迫逻辑 | "没人看见，随便我怎么样" | "大家都看着，但大家都默认" |

核心点：**场合切换不是攻方变脸，是攻方的同一套控制拆成两半用**。私下给受方"不可告人的把柄"，公开用这个把柄施压\~受方最怕的不是私下被弄，而是"被人知道"这件事本身。

## 二、公开场合的暗语威胁（"放学后来办公室"类）

### 私下行为
- 兑现威胁：把暗语里的命令执行掉，单独调教/轮奸/惩罚，通常是整套流程（命令→检查→插入→规矩）。
- 受方对暗语的理解从"听不懂"到"一听到就身体发紧"——暗语系统靠私下的重复建立。
- 反应库·威胁式：威胁对象具体可感（身体/名声/亲人），条件句、层级、威胁+微笑（来源：男性施暴方反应库_细化版.md 三④）。

### 公开行为
- 用完全正常的公开台词发布命令，字面上挑不出毛病，只有受方听得懂第二层意思。
- 说话语气、称呼、站位、眼神都在演"没事"，周围人听到的是一句普通的话。
- 公开台词带制度包装：辅导、值日、处罚、奉仕、实习——命令藏在制度里。
- 当着所有人的面说，等于故意给受方加一层"你不敢当众反驳"的压力：你一说"不"，就得解释为什么。

### 切换手法
1. **暗语系统建立期**：先私下做一次"教学"，把特定词和命令绑死（参考学园长强制命名：おちんちん→チンポ、お尻→ケツマンコ，"正しく、もう一度！"的纠正复述，女装学校01_本番）——暗语越私密，公开使用时受方越羞耻。
2. **公开台词=正常事务**：命令藏在"校则""处罚""面谈""奉仕安排"里，旁人听是公事，受方听是通知（町ぐるみ的志愿奉仕：会館奉仕/バス奉仕/学園奉仕，伪装义务劳动实为性服务，町ぐるみ_提炼.md 一1.3）。
3. **威胁+微笑**：公开场合说暗语时攻方表情越正常，受方越怕——"正正常常地笑着把最脏的话说出来"（反应库·威胁式）。
4. **留白式威胁**：不说完，只给半句，让受方自己脑补（"放学后来办公室"后面没说的内容比说出来的更吓人）。

## 三、当着家人/外人面装作关怀实为控制

### 私下行为
- 越界本体：独处时调教、乱伦、把受方当私有物，伦理话术正当化（"女はみんなこの穴を空けて大人になるんだからな"，家族型，攻方人物类型库 三）。
- 私下可能更"温柔"（温柔哄骗型：动作慢、边哄边做、还帮擦眼泪，"爸爸爱你才这样"，反应库 四③）也可能更粗暴——但关键特征是**私下才露出占有者的真面目**。

### 公开行为
- 当着家人/外人面维持原身份：爸爸还是爸爸、老师还是老师、校长还是绅士。
- 关怀话术加倍（"多穿点""早点回家""最近学习怎么样"）——关怀本身变成控制的掩护：旁人眼里他是关心，受方耳朵里全是警告。
- 公开场合绝不提那件事，甚至会对受方额外好（奖励姿态），让受方连"告状"的入口都没有——说出去没人信，因为他在人前毫无破绽。
- 威胁藏在关怀里：当着全家人的面说"吃完饭来我房间一趟，爸有事跟你说"——字面是家常，实际是命令。

### 切换手法
1. **人设分离**：公开形象（长辈/绅士/老师）和私下攻方是同一个身体的两张脸，切换靠"正当理由"（辅导/面谈/照顾/处罚）。
2. **家常式对冲**：威胁源在场时正常对话，另一边继续私下的事——"你快点啊我憋的很""你怎么还看黄片"——妻子在隔壁正常对话，这边正操着女儿（反应库 五⑤家常式）。场合的物理边界（一墙之隔）就是攻方最爽的玩法：公开在耳边，私下的手不停。
3. **偷情式扫尾**：事后悔净、擦干净、别让她发现（反应库 二⑥"擦干净，别让她发现了"）——维护公开人设的手段，比威胁本身更显示控制力。
4. **称呼切换**：公开用亲昵日常称呼（"女儿""乖"），私下改叫法（"我的女人""母狗"）——称呼本身就是场合开关（家族型：日常还是"爸爸/哥哥"的称呼，越界时用伦理话术）。

## 四、多人面前的公开羞辱（"让大家看看你是什么"类）

### 私下行为
- 单独调教：一对一开发、立规矩、给受方建立"只有我们两个知道"的羞耻账本——公开羞辱的素材（身体的反应、称呼、习惯）全在私下阶段收集。
- 私下时攻方往往掌控节奏（快慢、深浅、允许与否），受方尚存一点"没别人知道"的遮羞布。

### 公开行为
- 把私下的内容搬到台面上：公开宣布受方的身份标签（"让大家看看你是什么"），当众展示受方的身体反应，让围观者参与（点评/起哄/接力）。
- 公开羞辱的核心不是攻方一个人羞辱，是**把全场观众变成共犯**——起哄的、点评的、接力的、围观的，人人沾手，受方从此没法向"大众"求助，因为大众本身就是加害者。
- 舞台化：朝礼台、教室讲台、写生课、摄影棚——公开场合本身成了"展示装置"，攻方像主持人一样指挥（群P主导者：控制顺序/进度/分配、规则宣布，反应库 四⑤）。

### 切换手法
1. **名义化包装**：公开羞辱必须有"正当名义"才成立——处罚（校则違反）、写生（クロッキー）、摄影（パンフレット）、奉仕（志愿活动）、持久力特训（部活）。名义一立，围观者就敢看、敢参与（女装学校的"合法化包装"：授業/実習/モデル/朝練/写生/交流会，女装学校 十5）。
2. **当众点评**：公开场合由攻方（或攻方授意的人）当众评价受方的身体/反应/身份——"让大家看看你是什么"的实义化。点评由权威角色开口（校长/老师/町长/老人），起哄由群众角色接（学生/围观者）。
3. **围观者接力**：从"看"到"上手"——先是围观，再是点评，再是排队（学園ぐるみ每天列队；クロッキー5分钟轮换；陆上部3分钟计时）。公开羞耻的浓度随着参与人数递增。
4. **称呼公开化**：私下起的侮辱性称呼拿到公开场合用（肉便器/オナホール/精液便所，从私下命名→公开叫→受方自认，女装学校 十8"命名→自认"堕落链）——称呼的公开使用=羞辱的正式化。
5. **现场对质**：故意在特定观众面前做（在暗恋对象面前、在家人面前）——公开羞辱挑观众，观众越"重要"，羞辱越狠（前島："私に好意を持っていながら、その男の前でアヘアヘ喘ぎまくるとはな"）。

## 五、切换手法的通用机制（汇总）

1. **暗语系统**：私下建立词汇-命令绑定，公开场合用正常台词触发（"放学后来办公室"）。绑定越私密，公开使用越有效。
2. **正当名义**：每次公开施压都有制度包装（辅导/处罚/奉仕/写生/面谈），旁人听到的是公事。
3. **人设双轨**：公开面孔（绅士/父亲/老师）零破绽，私下面孔（占有者）只在独处出现；维护公开人设的手段本身也是控制（扫尾、擦干净、加倍关怀）。
4. **共犯转化**：围观者从"证人"变成"参与者"（起哄→点评→接力→排队），受方的求助通道被自己堵死——"大家都看到了，但没人会帮你"。
5. **威胁内嵌**：公开台词里藏威胁（"要是被人看见你和我在厕所里这幅样子，你觉得会怎样？"反应库 三④），公开场合本身成为威胁素材——最怕"被人知道"的受方，被"公开"两个字拿捏。
6. **场合递进**：私下→半公开（一墙之隔/耳机/关门）→公开（当着人）→制度化公开（每天列队/全校集会）——同一种控制按暴露面逐级加码，受方的羞耻和无力感同步加码。
