## 使用总则（先读这个）

### 1. 三个名词先说清

- **攻方** = 主动的一方（主动靠近、主动试探、主动越界）。不一定是"上位者"，えすめい里加奈（侄女、小孩）是攻方，大人是受方。
- **受方** = 被靠近、被试探、被越界的一方。受方的"反应线"决定这次互动能走多远：僵硬 → 假装没注意 → 默许 → 主动贴近。
- **暧昧点** = 这个互动里"从正常滑向越界"的那个具体动作/眼神/一句话。**暧昧点不是H**，是H门口的那一步。

### 2. 铺垫三件套（每个互动至少写两样）

| 工具 | 写法核心 | 关键 |
|---|---|---|
| **身体接触** | 写"停留时间"——碰了多久、什么时候收回去 | 收手=日常，停留=变味。同一个摸头，摸一下收手是正常的，手停在头发上就是暧昧 |
| **眼神** | 写"谁先看谁、看多久、谁先移开" | 先移开的人更心虚。不写心理活动，光写"看了多久才移开"，氛围就变了 |
| **话语** | 三档：正常档（干净日常）→ 夹带档（话正常，语气/停顿不正常）→ 越界档（话开始带别的意思） | 档位不能跳，对话的变质速度=关系的变质速度 |

### 3. 场景铁律：写清谁在、谁不在

- 不在场的人就是后面的"空窗"——越界都发生在没人的时候。
- 每段日常开头的场景设定必须交代：在哪、什么时候、几个人。

### 4. 收尾三种（决定这段日常往哪走）

- **正常收尾**：各回各屋，什么也没发生（拉长铺垫用）。
- **埋线收尾**：留一个没说破的东西（一个眼神、一句没说完的话、一扇没关严的门）——下次从这儿进。
- **越界收尾**：直接滑向H（接 H模板的进入方式）。

### 5. 八类互动怎么选

- 先定走向（堕落线/纯暴力线/纯轮奸线），再选互动。堕落线用本库的"暧昧点"做渐变铺垫；纯暴力线禁止甜蜜互动，日常只做反差；纯轮奸线的日常里互动是单向的。
- 每段日常只选一个主互动，别同时铺三件（吃饭就吃饭，别又吃饭又辅导作业）。

## 一、吃饭

### 场景

晚饭时间，餐桌。两三个人，或只有两个人。谁不在场很重要——妈妈上夜班、哥哥出差，饭桌上只剩两个人的时候，最普通的夹菜都会变味。地点细节：餐桌上摆什么菜、碗筷的位置、谁坐谁对面、灯光亮不亮。

### 角色行为

- **受方**：低头吃饭、夹菜、说今天发生的事、吃完主动洗碗、盛饭。动作要日常，但可以写"话变少了""筷子停了一下"这种细变化。
- **攻方**：夹菜给对方、推盘子、盛汤、问"吃饱了吗"。从"顺手夹一筷子"到"专门挑对方爱吃的夹到碗里"，就是递进。

### 暧昧点（怎么从日常滑向越界）

1. **夹菜递进**：顺手夹 → 专挑爱吃的夹 → 夹到碗里还要看着对方吃 → 夹起来直接喂到嘴边。每一级都要隔几顿饭，不能一顿饭全走完。
2. **手的停留**：递碗、递筷子、碰杯的时候手碰到一起——正常是碰到就缩，暧昧是"碰到之后谁也没先收回去"。写清停留的秒数和收回的时机。
3. **桌下的接触**：餐桌是"上半身正常、下半身可以偷偷发生什么"的天然掩护。脚的碰触从"不小心踢到"开始，第一下要装成意外。
4. **话语夹带**："吃饱了吗"→"饱了没？再吃点"→"你吃得太少了，是不是哪里不舒服"（关心变质的入口：用"照顾"的名义追问）。
5. **吃饭的位置**：从对面 → 挨着坐 → 坐同一侧。座位距离是关系温度最直观的尺子。
6. **空窗利用**：只有两个人的晚饭，饭桌上聊的话题从"学校/工作"慢慢变成"私人话题"——今晚谁先聊到"小时候""过去的事"，谁就在拉近距离。

### 案例

- 《无意引诱》：爸爸给女儿夹菜、削苹果、喂饭——日常照顾是铺垫主力，苹果皮削得断断续续这种小细节写出"重复的日常"。（来源：日常场景通用模板.md 阶段0示例）
- えすめい：仆人化日常——加奈命令主角早起做早餐、不能同桌吃饭，后来"被允许同桌吃饭"成了恩赐（scn_37 6/28同居日常）。**同桌吃饭=关系等级的试纸**：不能同桌→同桌→被夹菜，每一步都是关系变化的标记。（来源：えすめい_提炼.md）
- むすめーかー：gohan目录=与女儿吃饭的日常场景（生日/圣诞/情人节/食事）。**节日吃饭=仪式感强化**，生日蛋糕、圣诞晚餐这种"一年一次"的饭局，是关系突破的天然舞台——日常吃饭铺垫温度，节日吃饭推剧情。（来源：むすめーかー_提炼.md）

## 二、看电视

### 场景

晚上，客厅，沙发。电视开着，灯光暗（或只开一盏灯）。毯子、遥控器、茶几上的零食是必备道具。谁在谁不在：白天全家人看的客厅，晚上只剩两个人的时候，沙发就变味了。

### 角色行为

- **受方**：坐在沙发上看电视、盖毯子、抢遥控器、看着看着打瞌睡。打瞌睡是经典动作——"睡着了"给攻方提供合法的靠近理由（盖毯子、扶头、挪位置）。
- **攻方**：换台、递零食、问"看这个行吗"、坐得越来越近。从"沙发两头"到"中间"到"挨着"到"怀里"，距离是递进刻度。

### 暧昧点（怎么从日常滑向越界）

1. **距离递进**：沙发两端 → 中间隔一个靠垫 → 靠垫被拿开 → 挨着坐 → 肩膀靠上。每集电视推进一点点，别一晚上就坐进怀里。
2. **毯子下面**：毯子是"看不见的掩护"——毯子下发生了什么只有两个人知道。从"共用一条毯子"开始，毯子下的手从"放自己腿上"到"放两人中间"到"放对方腿上"，是经典递进线。
3. **打瞌睡的靠近**：受方睡着 → 攻方盖毯子、扶头靠到自己肩上 → "你睡着了，我不好动"成为停留的理由。醒来后谁都不提，但下次睡着位置更近。
4. **换台时的触碰**：抢遥控器的时候手碰到手——和吃饭递东西一样，写停留。抢着抢着变成"把手按在对方手上不放"。
5. **话语夹带**：讨论剧情的时候聊到感情戏，"你觉得他俩算在一起了吗"——借电视里的故事问现实里的关系，问的人心虚，听的人知道。
6. **黑暗的掩护**：电视屏幕光是客厅唯一的光源，暗处适合发生"看不清但感觉得到"的事。光线被调暗=要出事了，是给读者的信号。

### 案例

- えすめい：人椅play的借口就是"テレビを見たい"（我想看电视）——电视成了日常借口，攻方用"看电视"的名义把受方当椅子用。（来源：えすめい_提炼.md scn_16，SM部分本身不适用，但"看电视=独处借口"这个框架可复用）
- むすめーかー：王様ゲーム是周日固定事件之一——"大家坐在一起看电视/玩游戏"的群体日常里塞一个游戏，游戏里出现"国王命令"，把日常聚会变成越界舞台。（来源：むすめーかー_提炼.md）
- 《无意引诱》：客厅沙发是主要越界场地，看电视时坐怀里、手放腿上是阶段3"习惯化"的写法——过去越界的事变成没人觉得奇怪的日常。（来源：日常场景通用模板.md 家庭类）

## 三、睡觉

### 场景

夜晚，卧室或客厅沙发。睡衣、被子、枕头、床头灯、走廊的灯。门关不关是重点道具——**门没关严是经典埋线**。睡觉是"最放松=防御最低"的时间段，也是"假装睡着"最好用的时候。

### 角色行为

- **受方**：道晚安、回房间、关灯、盖被子。睡着的状态=无法反抗的状态，所以"睡着"前后的描写特别重要——真睡还是装睡，是这条线的分水岭。
- **攻方**：道晚安、帮盖被子、关灯、在门口多站一会儿。从"道完晚安就走"到"在门口站一会儿"到"进来坐床边"到"坐床边不走"，每一步都是进攻。

### 暧昧点（怎么从日常滑向越界）

1. **晚安亲亲递进线**（经典模板）：额头 → 脸颊 → 嘴巴 → 浅吻 → 深吻。每级之间隔很多天，而且每级都要有"对方没躲"这个前提才敢走下一级。亲额头是正常的，亲完不走是暧昧的。
2. **盖被子的手**：盖被子这个动作本身正常，但"整理被角的时候手停在被子上"、"顺手把头发拨到耳后"、"掖被角的时候指尖擦过肩膀"——照顾动作里夹带接触，是阶段2"借照顾名义触碰"的标准写法。
3. **门与灯**：门从"关严"到"留一条缝"到"不关"，灯从"全关"到"留走廊灯"——环境的每一步变化都是关系的进度条。埋线收尾最爱用"门没关严"。
4. **夜里的敲门**：从"半夜起来喝水路过"到"敲门问睡了没"到"进来坐一会儿"到"进来躺下"。频率和时长是刻度。
5. **装睡的博弈**：受方装睡，攻方知道她装睡，两个人都演——这种"都知道但不说破"是睡觉线最色的部分。写受方装睡时的呼吸变快、眼皮颤动。
6. **醒来后的尴尬**：早上醒来发现睡在一起/靠在一起，谁先动、谁先说话、谁假装没发生过——醒后处理决定下一次还敢不敢。

### 案例

- 《无意引诱》：亲亲递进模板（额头→脸颊→嘴巴→浅吻→深吻）是睡前晚安线的完整范本。（来源：日常场景通用模板.md 家庭类·睡前晚安）
- 炉姦12 ch4：睡衣+毛毯是睡奸场景的服装道具——从"穿睡衣盖毛毯睡觉"这个日常状态直接进H，日常感越强，越界的反差越大。（来源：炉姦12_提炼.md，H部分不适用，睡衣毛毯的"日常锚定"可复用）
- 迷宮都市アサイラム：调教事件在"睡觉"和"沙发休息"这种日常场景随机触发——性完全嵌入生活动线，比固定调教房更堕落。（来源：迷宮都市アサイラム_提炼.md 事件触发式）
- えすめい：加奈的真心期用"一行短信"（"明日、アパートに行く"）——睡觉前的留白式交流，短句比长句更有重量。（来源：えすめい_提炼.md 真心期台词）

## 四、洗澡

### 场景

浴室。水声、热气、门、浴巾、换洗衣服。门缝透光是经典环境细节（外面能看到里面的光）。洗澡是"身体暴露+封闭空间+水声掩护"三合一场景，也是"递东西"最频繁的地方。

### 角色行为

- **受方**：进浴室、脱衣服、洗澡、洗头、出来时裹浴巾。写水声、热气、光，不写身体（留白）。
- **攻方**：递浴巾、递换洗衣服、问"水温合适吗"、在门外说话。从"递完就走"到"在门口多站一会儿"到"门没关严"到"直接进去"。

### 暧昧点（怎么从日常滑向越界）

1. **递东西的时机**：受方洗到一半发现没拿毛巾/换洗衣服，喊攻方帮忙递——这是受方"主动制造暴露机会"的入口，也是攻方"合法靠近"的入口。递的时候写"从门缝里伸进去的手"，写门开多大、关多快。
2. **门与蒸汽**：门从关严 → 留缝（"怕你闷"）→ 不关（"就我一个人"）——门的开放度=信任度=越界进度。
3. **水声掩护**：水声可以盖住说话声和别的声——"水声这么大没人听见"是攻方的心理支撑，也是受方"明明知道但没阻止"的理由。
4. **洗头/吹头发**：帮洗头、帮吹头发是"照顾名义"的黄金动作——站得近、摸头发、指尖碰头皮，全是接触，但全都有"照顾"的外衣。吹头发的时候头发丝蹭到对方的手，写这个细节。
5. **话语夹带**：隔着门说话——"衣服放门口了""毛巾在架子上""水温我调好了"。从"报信息"到"闲聊"到"问里面好了没"（催，但催里带别的意思）。
6. **空窗利用**：家里只有两个人的时候，洗澡时间就是"最危险也最安全"的时间——谁都可能突然出来，谁都可能被看到。写这种"随时会被撞见"的紧张感。

### 案例

- えすめい scn_22：风吕场突袭——加奈穿スク水闯入浴室，反差感来自"日常的浴室+突然的闯入"。（来源：えすめい_提炼.md，具体H内容不适用，"浴室突袭"的框架可参考）
- 《无意引诱》：共浴舔阴、递浴巾是浴室线的越界入口——浴室是"家庭类"里越界密度最高的场景之一。（来源：日常场景通用模板.md 家庭类·洗澡）
- 父性breakdown：序章回顾"洗澡陪伴"是父爱的日常记忆之一（夜泣き陪伴、洗澡、看病、运动会、入学式）——**洗澡陪伴=亲密关系的历史证据**，回忆里的正常洗澡，反转为后来的越界舞台，落差感最强。（来源：父性breakdown_提炼.md 2.1）

## 五、上学（校园）

### 场景

上学路上、教室、课间、放学后。校服、书包、课本、座位。校园的特点是"人多但总有角落"——教室人满的时候最安全，放学锁门后最危险。值日、辅导、课后独处是经典空窗。

### 角色行为

- **受方**：上课、记笔记、传作业、放学收拾书包。校园里受方往往是学生，攻方可以是同学、老师、或家里来接的人。
- **攻方**：接送、辅导功课、值日留到最后、在门口等。从"顺路一起走"到"专门来接"到"放学后找理由单独留她"，是递进。

### 暧昧点（怎么从日常滑向越界）

1. **辅导功课的靠近**（伪教育合理化）：讲题的时候凑近看作业本 → 手从纸边滑到桌边 → 检查作业的时候肩膀挨上 → "这里写错了"手直接点在本子上（手指碰到手）。辅导是校园线最大的越界入口——有"教育"的名头，一切靠近都有理由。
2. **上学路的同行**：从"顺路碰见"到"约好一起走"到"每天等她"——同行本身就是关系确认。路上买零食、分着吃、说话越来越近。
3. **传纸条/传作业**：纸条从"作业答案"到"闲聊"到"写了不敢递出去又递出去的话"。桌下的手、课桌间的传递，是课堂里唯一不被看见的通道。
4. **值日的空窗**：放学后值日留到最后 → 另一个也留到最后 → 锁门后教室里只剩两个人。值日表是天然的独处借口——"今天该我值日"。
5. **更衣室/储物柜**：换衣服、拿东西、门没锁——换到一半有人进来是经典桥段，但从"敲门问在不在"开始写，别直接进来。
6. **话语夹带**："放学等我一下"→"我送你回去"→"别跟别人说今天的事"——"只有我们知道"这种秘密感是校园线拉近距离的特效药。

### 案例

- 女装お嬢様学校：每个H场景的冒頭都安排"下一次H的借口"（学园长指定模特/指定プール/宿直当番/赞助商交流）——**校园制度本身是越界借口生成器**，"宿直当番"（值夜班）这种日常职责就是独处的合法理由。（来源：女装お嬢様学校_提炼.md）

- 101148：秘密基地的儿童日常（建基地、玩闹、孩子王）——上学/暑假的日常感是"胜负游戏"展开的底色，天真日常反衬后面的一切。（来源：101148_提炼.md）

## 六、逛街

### 场景

商店街、商场、内衣店、试衣间、小吃摊、回家的路。人多的地方反而适合"人看不见的小动作"，人少的地方适合"停下来说话"。试衣间、巷子口、公交站是经典节点。

### 角色行为

- **受方**：看东西、试衣服、买小吃、走前面或走后面。走位有讲究——走前面=把后背留给对方，走后面=看着对方的背影。
- **攻方**：跟着、提东西、付钱、评价"这件好看"。从"跟在你后面"到"走在你旁边"到"拉着你走"到"搂着你走"，并排的距离和接触是递进。

### 暧昧点（怎么从日常滑向越界）

1. **人群里的手**：人多的街道上自然靠得近 → 手背碰到手背 → "人多怕走散"拉手 → 拉着不松。每个阶段都有"人群"这个借口。
2. **试衣间**：受方试衣服，攻方在帘子/门外等——"这件行吗"隔着帘子问，帘子拉开的瞬间、门没锁紧、换到一半有人敲门。试衣间是逛街线最经典的越界舞台（私密空间+随时有人进来的紧张）。
3. **买内衣/贴身衣物**：陪买内衣本身就是关系测试——从"路过内衣店"到"陪进去"到"给意见"到"替她挑"，每个台阶都有"帮忙"的外衣。被店员当成情侣/父女/兄妹的误会，写这个尴尬。
4. **吃的分享**：买一份小吃两个人分——"你先吃"到"喂你一口"到"直接递到你嘴边"。同吃一份食物的亲密感比想象中强，因为共用唾液是潜意识里的越界。
5. **走散与寻找**：人群里走散 → 找到的时候"终于找到你了"的松口气 → 松口气之后自然拉上的手。走散是"合法重逢"的桥段，重逢时的反应写真实情绪。
6. **顺路变弯路**：回家的路从"直路"到"绕远路"——"再走一会儿"的借口是"天还早""那边新开了一家店"。绕路=想多待一会儿，谁提绕路谁心虚。

### 案例

- 《无意引诱》：内衣店试衣间场景（妈妈在隔壁）——**试衣间+亲人在隔壁**的双重紧张，是最经典的逛街越界舞台。（来源：日常场景通用模板.md 公共类·逛街）
- えすめい scn_05-06：商店街被加奈目击主角买成人漫画——逛街时的"被目击"是悬念铺设：**逛街=公开场合=随时可能被认识的人看见**，这个风险感本身就是张力。（来源：えすめい_提炼.md）
- 迷宮都市アサイラム：散步线（魔犬と散歩）——从"日常散步"到"散步途中发生事"，散步是"边走边发生"的渐进场景。（来源：迷宮都市アサイラム_提炼.md，具体内容不适用，散步框架可参考）

## 七、游戏

### 场景

客厅（游戏机）、房间（卡牌/桌游）、手机（联机）。游戏的特点是**有规则、有输赢、有惩罚**——规则是越界最好的掩护："输了就要听我的"。游戏机、卡牌、乒乓球拍这些日常道具是"日常道具调教"的起点。

### 角色行为

- **受方**：认真玩、输了认罚、赢了得意。游戏里的反应（较真、耍赖、求饶）比平时更真实——输赢让人卸下防备。
- **攻方**：提议玩游戏、定规则、放水或认真赢、提惩罚。从"玩游戏"到"定惩罚规则"到"惩罚内容越来越私人"，是攻方的进攻线。

### 暧昧点（怎么从日常滑向越界）

1. **输赢框架**（罚ゲーム模板）：游戏胜负 → 输家听赢家一个命令 → 命令从"打扫卫生"到"帮我捶肩"到"坐过来"到更越界的内容。**框架是合法的，内容一步步变形**——攻方要"必赢"（设定全能人设），这样每次命令都有理由。
2. **肢体接触藏在游戏里**：双人游戏的手柄/手碰手、卡牌对战时的靠近、输了被"弹脑门""挠痒痒"——惩罚是接触的合法入口。
3. **距离递进**：坐着玩 → 挨着玩 → 攻方从后面看受方打 → "我教你"从后面握住手。教人玩=贴身的合法理由。
4. **赌注升级**：每次追加赌注——从"洗碗"到"答应一个要求"到"存着以后用"。"欠我一个要求"是埋线收尾的经典用法，欠着欠着就还不清了。
5. **游戏里的对话**：游戏时间=最放松的说话时间——聊的话题从游戏到学校到私事，"边玩边说"的话比正襟危坐更容易说出口。
6. **孩子气的合理化**：受方用孩子的逻辑说服自己（"游戏规则就是这样""说好了输的要听"）——规则一旦被接受，越界就有了"他也没办法"的遮羞布。

### 案例

- えすめい：罚ゲーム是全线核心框架——"负けたら、罰ゲームするというのはどう？"（输了就玩惩罚游戏怎么样），加奈游戏全能必赢，每个命令都有"游戏规则"的外衣。升级方式是每次追加赌注。（来源：えすめい_提炼.md 模板1）
- いじめっ子 h9：卡牌对战决定姐姐的命运（人质游戏）——**游戏=性爱筹码**，日常物品（卡牌）的色情化。（来源：いじめっ子_提炼.md，具体内容不适用，"游戏决定关系"框架可参考）
- 101148：セックス勝負（性爱对决）——用"比赛/胜负"框架包装一切，受方以为自己在战斗，实际在主动学习。框架：设定赌注→教新玩法→食言不认账→追加赌注。（来源：101148_提炼.md 结构四）

## 八、共处沉默

### 场景

同一个房间里，各做各的事，不说话。客厅（你看手机我看书）、厨房（一个做饭一个等饭）、阳台（一起晾衣服）、夜晚的客厅（电视开着没人看）。**沉默是最难写也最色的日常**——没有对话，全靠身体和眼神。

### 角色行为

- **受方**：不说话，低头做事。沉默里的人最容易暴露真实状态——呼吸、坐姿、翻书的速度、玩手机时屏幕内容（心不在焉的话屏幕会停在同一页）。
- **攻方**：也不说话，但看着对方。沉默里的看是最直的——"没话找话"是心虚，"沉默着看"是蓄谋。

### 暧昧点（怎么从日常滑向越界）

1. **沉默里的眼神**（眼神线的主力战场）：先看对方 → 对方发现 → 移开 → 过一会儿又看——"看多久、谁先移开"是全部台词。**先移开的人更心虚**，写这个。
2. **沉默里的身体语言**：坐姿转向对方的方向、脚不自觉地朝对方、呼吸放慢、衣服摩擦声——沉默时声音被放大，写"房间里只有翻页声和空调声"这种环境音，然后写"谁的呼吸声变了"。
3. **递东西打破沉默**：倒水、递水果、挪一下坐垫——沉默里的一次递东西比热闹时的十句话都重。"接的时候手指碰到，两个人都不说话"——全库最经典的暧昧写法。
4. **没话找话的失败**：攻方憋了半天说"明天天气不错"这种废话，受方"嗯"一声，又沉默——失败的搭话比顺利的对话更暴露心思，写这个尴尬。
5. **沉默的收尾**：沉默一段后，一方说"我去洗澡了/我先睡了"——打破沉默的那个理由越假，越说明刚才的沉默有内容。"我先睡了"的潜台词是"再待下去我不知道会发生什么"。
6. **背对与靠近**：背对做事 → 感觉到对方走近 → 没回头 → 对方在身后站住——"背后的人"这个位置本身就暧昧，写背对时后颈发麻的感觉。
7. **沉默里的隐藏心思**（隐藏性癖期）：表面温柔/冷淡，心里藏着不敢说的想法——"（好想被加奈酱欺负…！）"（えすめい scn_01-06，受方内心暗恋+隐藏M性癖）。沉默越是若无其事，心里越翻涌——攻方点破前，受方的沉默=藏秘密；点破后，受方的沉默=被看穿的无地自容。**写"表面在做什么+心里在想什么"的错位，是这段的写法**。

### 案例

- えすめい：无口侄女加奈的日常就是沉默共处——"…おかえり""別に…""…考えておく"（我回来了/没什么/我考虑一下）——**短句+冷脸是沉默的极致**，攻方全程不说破，受方在沉默里自己紧张。（来源：えすめい_提炼.md 无口期台词）
- 日常场景通用模板：眼神线——"不写心理活动，光写'他看着她后颈看了多久才移开'，氛围就变了"；"去年才到自己胸口，今年超过肩膀"用看的视角带出身体变化。（来源：日常场景通用模板.md 眼神变化线）
- むすめーかー：日程养成（学习/打工/接待/休息）穿插日常事件——**共处的常态本身就是关系的一部分**，天天见面、天天沉默、天天看，累积感是长期铺垫的核心。（来源：むすめーかー_提炼.md）

## 一、六期总框架（统一堕落进度表）

| 期 | 阶段名 | 日常里的样子 | 互动尺度 | 进度标记物 |
|---|---|---|---|---|
| **期1** | 正常 | 动作完全正常，接触短快无停留，眼神自然移开 | 正常接触（递东西碰手/拍肩/摸头） | 无，一切"应该的样子" |

## 二、七个日常动作 × 堕落期变化链

### 1. 吃饭

| 期 | 变化 | 具体写什么 |
|---|---|---|
| 期1 | 正常吃 | 围桌、夹菜、说学校的事、谁洗碗。递碗碰到手，短、快、无停留 |
| 期2 | 微变 | 坐得比平时近；夹菜放进你碗里手多停一下；看着你吃；"吃饱了吗"变"饱了没？再吃点" |
| 期3 | 被喂 | 借"你手冷/你吃得慢/看你吃"名义，第一口喂到嘴边。又惊又羞，吃也不是不吃也不是 |
| 期4 | 喂成习惯 | 喂饭变日常，没人觉得怪；饭桌上开始说性话题不当回事；坐怀里吃/坐腿上吃 |
| 期5 | 跪着吃/吃精液 | 自己的饭在桌上，人在桌下；或"吃"的内容变了，精液当加餐，咽下去不皱眉 |
| 期6 | 侍奉式吃饭 | 吃饭=侍奉流程：先服侍攻方吃完，自己等投喂/吃剩下的；被喂精液当早餐不觉得怪 |

**案例**（中文+来源）：
- 期1：日常模板"阶段0正常"——正常喂饭/做饭/称体重的日常铺垫（《无意引诱》前几章，来源）。
- 期2：日常模板"阶段1微变"——坐腿/贴贴/亲额头那类过分亲密日常（《无意引诱》，来源）。
- 期4：日常模板"阶段3习惯"——越界日常化，日常活动夹带性意味（《无意引诱》中后期，来源）。
- 期5：日常模板"纯轮奸线"——餐桌上被操、跪在桌边等投喂的公用化日常（《女学生成为公用的肉便器》，来源）；えすめい仆人化日常——不被允许同桌吃饭，被允许同桌是恩赐（えすめい scn_31/scn_37，来源）。
- 期6：えすめい"被允许同桌吃饭的恩赐感"——恩赐式口吻"……いいわ。取ってあげる"（えすめい，来源）；其余细节【推理】。

**渗透写法要点**：
- 餐桌是"家庭感"最强的地方，在这里越界反差最大——家里最像家的场景最先变味。
- 用"夹菜"练停留：夹菜→手停在碗沿→眼神→谁先移开。同一个夹菜动作，收手是期1，停着是期2。
- 名义化：喂饭用"关心"（你手冷/你嘴小/你吃太慢），照顾的名义是越界最好的入口。
- 位置变化就是进度条：同桌→坐近→坐怀里→坐腿上→桌下→跪着。写位置，不写心理，进度自然出来。
- 食物与精液的双关是期5的爆发点："吃点好的"这句话在期1和期5意思完全不同。

**案例**（中文+来源）：
- 期1：日常模板"洗澡"条目——浴室、水声、递毛巾、门（来源）。
- 期3-4：えすめい风吕场突袭——穿スク水闯入浴室，浴室从私密空间变调教场（えすめい scn_22，来源；方向是攻方闯入，可借鉴"闯入"结构写被看与被洗）。

**渗透写法要点**：
- 水声是双面道具：既是预警（谁来了）也是掩护（盖住声音），期4之后"水声盖住喘息"开始出现。
- 浴室是"独处+裸体"双高危场景，越界入口最多：递毛巾、门缝、共浴、滑倒借口。
- 被洗是从"自主"到"被管理"的象征链：自己洗→被看着洗→被洗→被检查。洗这个动作本身就是支配——"我帮你洗"的潜台词是"你的身体归我管"。
- 擦背是期4的标准入口：背对着看不见，手从肩到腰，往下是试探的天然路线。

| 期1 | 自己睡 | 道晚安、亲额头、盖被子、关灯、门关上，各回各屋 |
| 期2 | 微变 | 道晚安拥抱变久；门不关严；夜里敲门变多，说两句没要紧的话 |

**案例**（中文+来源）：
- 期1-2：日常模板"睡前晚安"条目——亲亲递进模板（额头→脸颊→嘴巴→浅吻→深吻）（《无意引诱》，来源）。
- 期3：gal渐进"迷宮都市"调教A——发情状态下睡觉被舔醒，睡眠场景触发调教（gal渐进，来源）；炉姦12睡眠侵犯类结构【推理补足】。
- 期6：日常模板"纯轮奸线"——早上被父兄晨勃操醒再去上学（《女学生成为公用的肉便器》，来源）。
- 期4-5细节【推理】。

**渗透写法要点**：
- 睡前是防御最低的时间点，越界大多发生在睡前后——"非常时刻"降低防御，这是日常模板明写的规律。
- 门这个物件是睡觉动作的进度条：关着→不关严→被推开→不关了。写门，不写心理。
- 写"醒来"比写"睡着"更色：晨勃唤醒是每天早上的固定提醒，把"被使用"写进生物钟。
- 道晚安的拥抱时长就是堕落温度计：一秒→三秒→不松手→亲一下→手往下。每期加一点，别跳。

**渗透写法要点**：
- 厕所是最后的私密堡垒：攻克它=堕落完成的标志。其他动作都变味了，厕所还锁着门，读者就知道进度没走完；厕所的门也开了，堕落就到底了。

- 素材缺口：此动作案例几乎全靠推理，重构时优先补素材。

## 三、跨动作通用渗透工具（汇总，写作时对照用）

1. **停留时间**：同一个动作，收手=日常，停留=越界。"停留是色和正常的唯一区别"（日常模板核心工具），七个动作全部适用。
2. **借口化**：每个越界挂一个"关心/游戏/练习/教学"名义（喂饭=关心、朝练=训练、留堂=辅导、人椅=想看电视）。借口越来越薄=进度越来越深。
3. **环境道具双面性**：门（关→不关严→被推开→不关了）、水声/电视声（预警也掩护）、光线（调暗=要出事了）——三个动作共用同一套门进度条。
4. **位置变化=进度条**：吃饭（同桌→桌下→跪着）、睡觉（自己屋→同床→被抱着）、看电视（并排→怀里→当家具）——写位置，不写心理，进度自然出来。
5. **游戏规则化**（期2起）：游戏是越界的合法外衣——"输了听命令"（えすめい scn_08，罚game框架）。规则一旦被接受，越界就有"他也没办法"的遮羞布。游戏全能必赢的攻方=每次命令都有理由。
6. **主动求罚**（期4）：被调教后主动要求再来一局——"请再和我比一次！"（えすめい scn_16）。从"被动接受惩罚"到"主动要玩"，是游戏框架里最明显的堕落信号：输家开始期待惩罚本身。
7. **忠犬宣言**（期6）：主动宣告自己是支配方的狗——"我再次坚定了决心，要做加奈大人的狗"（えすめい scn_31）。宣言日常化=关系彻底定型，事后随口复述也不觉得怪（与事后关系库"变质"互引）。
8. **自觉服从·日常报告**（期6）：日常主动报告行程/身体状态，不需要命令就自觉（えすめい scn_27-43，忠犬期，推理）——"不用吩咐就做"是驯服完成的日常证据。报告本身变成日常对话的一部分，像说天气一样自然。
5. **语言标记**：称呼/敬语/命名/自称的变化踩在堕落转折点上（えすめい的加奈様、女装学校的チンポ/ケツマンコ强制命名）——语言改造先于行为改造。
6. **身体记忆化**：用反射倒推心理堕落（深呼吸反射、闻味兴奋、路过发痒、晨勃唤醒）——比纯心理描写更有说服力（女装学校核心手法）。
7. **低防御时段**：睡前、洗澡时、生病时、对方睡着后——"非常时刻"降低防御，越界大多发生在这里（日常模板手法）。
8. **期5后的"维持表演"**：性关系常态化后，日常变成遮羞布——白天正常吃饭上学，晚上/私下被使用，日常=掩护一笔带过（日常模板阶段4、女装学校"日常×调教双层生活"）。

## 四、使用规则（草稿）

1. **禁止跳步**：每期要经过，每期至少写一段日常（期3和期5是重点转折，可多写）。跳步=堕落没有落差，铺垫白写（日常模板铁律）。
2. **日常占比**：前期日常多（铺垫厚，第一次越界冲击大），期5-6后日常变少变短（日常=掩护，一笔带过）。
3. **素材缺口**：上厕所动作案例几乎全为【推理】；吃饭的期3（被喂）、洗澡的期5（被洗全身）、睡觉的期4-5、看电视的期4/6 也标了【推理】——重构时优先补这些缺口。
4. **期1-6框架**：由女装学校六段（抗拒→麻木→习惯→主动→恋心→雌堕）+ 日常模板五段（正常→微变→越界→习惯→变质）合并，后续按需微调。

## 一、定位

- 这是"日常细分"的一个子类：**同一对关系，私下和公开是两套行为代码**。私下是亲密/调教/支配的常态，公开是装正常关系的表演。
- 和通用模板的关系：四段式骨架不变，②日常动作和③互动细节按场合切换着写，④收尾过渡的写法=切换瞬间（差点暴露 / 暗号对上）。
- 适用走向：**堕落线变质后的维持阶段**（白天维持正常表演，背地乱伦——模板阶段4"日常=掩护"）、**纯轮奸线**（公开=系统包装，被全镇/全校当正常关系维持）。
- 核心张力引擎：**切换瞬间**。伪装戏的看头不在"装得有多像"，在"切换的那一刻有多险"。

## 二、核心概念：两套行为代码

| 项 | 私下代码（独处时） | 公开代码（外人在场时） |
|---|---|---|
| 称呼 | 私下专用称呼（主人/加奈様/宝宝/那三个字） | 正常关系称呼（叔叔/侄女/老师/兄妹） |
| 距离 | 坐怀里、贴一起、靠身上 | 半臂以上，不碰 |
| 接触 | 有停留的接触（摸头不收回、手放腿上） | 正常接触（短、快、无停留——模板"停留是色和正常的唯一区别"） |
| 话题 | 调教指令、暗语、私密事 | 学校/成绩/天气/工作 |
| 话语档位 | 越界档（夹带/命令/荤话） | 正常档（干净，一个字都不能带） |
| 道具 | 玩具、皮鞭、道具 | 书包、课本、碗筷——日常物 |

- **规则一（单向禁止）**：公开场合禁止使用私下代码的任何元素。一个称呼、一个眼神、一个习惯动作漏出去，就是暴露口。
- **规则二（残留允许）**：私下场合可以残留公开代码——一边叫着"叔叔"一边做私下的事，这种反差本身就是色点（えすめい全程：加奈私下调教时也常喊"おじさん"，公开词在私下用=刺激；反过来公开场合喊"加奈様"=玩火）。
- **规则三（伪装省力原理）**：真实关系本身是最省力的伪装。叔侄/父女/师生这种"本来就该亲近"的关系，对外根本不用撒谎，正常互动就是最好的掩护——伪装成本全花在"别把私下的事带出来"。

## 三、核心场景一：家人面前装正常

### 场景定义
"姐姐只是在辅导弟弟功课"型。家人（父母/亲戚/其他孩子）在场时，维持"正常家庭关系"的表演。这类伪装的特点是：**家人离得近、观察细、随时可能闯入**，所以切换必须最快、最利落。

### 私下日常（独处时）
- 辅导功课是越界入口（模板家庭类"辅导功课"）：讲题时手滑到腰、头凑近、贴着检查作业——先正常讲，讲到一半手的位置开始不对。
- 私下的日常可以是完整的调教日常（えすめい：白天上学，晚上罚ゲーム/调教部屋；用餐时也有"不能同桌吃饭"的仆人化规矩）。
- 私下称呼、私下动作全放开，门一关就变脸。

### 公开伪装（家人在场时）
- "姐姐只是在辅导弟弟功课"——手放纸面上，眼睛看题，话全是讲题的。所有私下接触全部清零。
- 对话用正常档：成绩、作业、明天吃什么。称呼用公开称呼。
- 家人的存在是"空窗检测器"：模板①场景设定要求写清谁在、谁不在——家人场合反过来，谁在场就是伪装对象，谁暂时离开就是"空窗"，越界都钻空窗（妈妈上夜班→爸爸和女儿独处）。

### 切换瞬间的张力（必写点）
- **闯入打断**：调教/亲密进行到一半，家人推门、来电、喊吃饭→动作瞬间弹开、声音瞬间变调、话头瞬间接住。接话要接得比动作还快，慢了就穿帮。
- **话头试探**：家人随口问一句，刚好戳中私下的事（"刚才在屋里干嘛呢？"）→用公开话题圆回去，圆得越自然，心跳越快。
- **身体痕迹**：吻痕、膝盖红、走路姿势不对→当场用正常理由解释（"撞到了""没睡好"）。

### 案例
- **えすめい 商店街目击（scn_05-06）**：叔叔在商店街买成人用品，被侄女加奈看见。加奈当场不点破，晚上吃饭时才问"今天在商店街吧"——公开场合（餐桌）用一句正常话敲打，叔叔瞬间冒汗，加奈又不继续追问。这是"话头试探"的标准写法：公开话题里夹私下事实，接话的瞬间就是张力。
- **えすめい 全裸接电话（模板11"日常×调教双层生活"）**：白天维持正常同居（做饭/上学/看电视），夜晚调教；妈妈从国外来电时，调教中途/全裸状态下必须用完全正常的声音接电话——电话=闯入的家人，身体是私下的，声音必须是公开的。这是"闯入打断"的极致案例。
- **えすめい 冷战伪装（scn_22-26）**：浴室突袭后暴発被赶出+冷战——私下闹翻了，但在外人（父母电话）面前两人都不提，表面照常。私下冲突在公开层面表现为"没有异常"，这个"没有异常"本身靠两人默契维持。
- **町ぐるみ 近親相姦线**：敦子与父亲发生关系后，在镇上、在妹妹面前维持正常父女——"お父さん"这个称呼公开场合照常叫，叫得越自然，背德感越重。

## 四、核心场景二：陌生人面前装正常

### 场景定义
"我们是兄妹"型。对陌生人（邻居、店员、路人、同学家长）自称"兄妹/亲戚/师生"，把私下关系包装成社会可接受的关系。这类伪装的特点是：**对方不了解内情，随便编都行，但细节要自洽**——不同姓要解释、年龄差要解释、亲昵动作不能做。

### 私下日常（独处时）
- 亲密/调教/支配的完整常态，不需要理由。
- 私下可以拿"公开人设"当play素材（"在外面叫哥哥，回来叫主人"式的反差play）。

### 公开伪装（陌生人面前）
- 人设自洽三件套：关系（兄妹/叔侄/师生）、名字（公开称呼）、来历（为什么住一起）。
- 距离感按人设来：兄妹可以并肩走、可以一起吃饭，但不可以搂腰、不可以摸头太久——外人眼里的"正常兄妹"尺度就是表演的边界。
- 遇到熟人/邻居要先对好口径：住在一起、什么关系、怎么称呼——口径不一致就是暴露口。

### 切换瞬间的张力
- **突然搭话**：走在路上被陌生人/邻居搭话（"这位是？"）→瞬间切换称呼和距离，暗号先确认对方是纯外人还是知情者。
- **称呼说漏**：习惯性喊出私下称呼，半路改口（"加奈……加奈ちゃん"）——改口的那个停顿，就是差点暴露的瞬间。
- **物件穿帮**：私下物件出现在公开场合（包装袋、道具、不该出现在书包里的东西）→当场找借口掩盖（えすめい：ボンデージ包装袋如果被看到，说成"cosplay道具"）。

### 案例
- **えすめい 全篇（叔叔×侄女）**：真实关系就是叔侄，对陌生人根本不用撒谎——"我是她叔叔"就是公开身份，正常带侄女出门、逛商店街全是合法掩护。这是"真关系=最省力伪装"的样本：伪装成本全在"性癖不被发现"（商店街进成人店差点暴露）。
- **町ぐるみ 敦子（教师身份）**：敦子在学生面前是"老师"，全镇人面前是"新搬来的老师"——公开身份是教师，私下被全镇轮奸。学生喊"先生/せ〜んせい"既是公开称呼也是性羞辱素材（"先生も、こうやって拘束されて犯されるのが気持ちいいんだろ？"）——身份面纱本身就是双面的：上课时是老师，放学后是玩具。
- **町ぐるみ 巴（被父亲卖掉的学生）**：长期被凌辱，但在同学、老师面前维持"普通学生"的样子——周围人全不知道，直到敦子调查才发现。公开伪装是"全镇合谋"里受害者的日常状态。

## 五、核心场景三：公开场合的暗号

### 场景定义
私下约定的词句/动作，在公开场合使用，表面是完全正常的话题，实际在传递私下信息。暗号的功能有三种：**确认安全、传递指令、公开调情**。

### 暗号设计要点
- 暗号必须"拆开看完全正常"：一句话、一个词、一个动作，外人听了看了都没问题，只有两人懂第二层意思。
- 常用载体：日常话题（"今天吃什么""要不要玩游戏"）、日常动作（摸某个位置、整理领口、重复词尾）、称呼变化（公开称呼在特定语境下=暗号）。
- 建立暗号的时机：私下场合约定，公开场合使用——约定的过程本身可以是一场私下戏。

### 切换瞬间的张力
- **暗号对上**：一方说出暗号，另一方用约定方式回应（眼神、动作、重复词）——对上的那一瞬间，两人在人群中完成一次私密交流，外人毫无察觉。这是"公开场合的隐秘调情"，比私下更色。
- **暗号没对上**：一方没听懂/忘了约定→另一方无法确认安全，或指令没传达→接下来就可能暴露或误事。
- **暗号被外人听见**：暗号说得太明显，被外人接了一句→两人瞬间紧张，要用更正常的话圆回去。

### 案例
- **えすめい 商店街试探（scn_05-06）**："今天在商店街吧"——加奈用一句公开场合的平常话，传递"我知道你去了成人店"的警告。外人听就是闲聊，叔叔听得懂言外之意。这是**警告式暗号**：暗号由施加方（加奈）发起，用来威慑受方。
- **えすめい 罚ゲーム（scn_08起）**："要不要玩游戏？"——公开场合说玩游戏=调教开始的暗号。游戏框架是整个调教关系的暗号系统：输赢、命令、惩罚全在"游戏"这个词底下进行。外人听就是小孩玩游戏。
- **えすめい 日常×调教双层生活（模板11）**：白天同居日常里夹的私下约定（几点睡、门关不关、什么时候可以进房间）——全是可以公开说出口的平常话，私下另有含义。
- **町ぐるみ 耳机传声（通勤痴汉巴士）**：幕后男声通过耳机向敦子下达指令，巴士上全是乘客——公开场合（通勤高峰）的隐藏指令通道。敦子必须表面装作无事地执行，周围人听不到耳机里的内容。这是**指令式暗号**：指令走隐秘通道，执行在公开场合，身体反应必须压住。

## 六、切换瞬间的写法清单

### 差点暴露（四种写法，每场伪装戏至少用一种）
1. **闯入打断**：调教/亲密进行中，家人推门/来电/喊话→动作瞬间弹开、声音瞬间变调、话头瞬间接住。接话要快过动作。（えすめい：全裸接妈妈电话）
2. **话头试探**：对方用公开话题敲私下事实（"今天在商店街吧"）→接话要接得自然，接完心跳才上来。（えすめい：晚餐试探）
3. **物件穿帮**：私下物件/痕迹出现在公开场合（包装袋、吻痕、走路姿势）→当场找正常理由掩盖。（えすめい：成人店被目击）
4. **称呼说漏**：习惯性喊出私下称呼，半路改口→改口停顿的那一下，是暴露与不暴露的分界线。

### 暗号对上（三种写法）
1. **确认式**：对方说出暗号→自己用约定动作/词句回应（眼神接触、重复词尾、摸约定位置）——对上的瞬间，两人确认"安全/都懂"。
2. **指令式**：公开场合收到调教/支配指令→必须表面正常地执行，身体反应压着走（町ぐるみ：巴士耳机传声）。
3. **警告式**：暗号=警告"现在别乱来/有人注意/我知道你的事"（えすめい：商店街试探）——暗号一出，受方立刻收敛或冒汗。

### 伪装失败线（可选走向，给故事转折用）
- 差点暴露→圆过去了（埋线收尾：暗号留一句没说破的话，下次再用）
- 差点暴露→真的暴露→关系破裂/被迫摊牌（町ぐるみ：巴被卖的事实被发现是剧情转折点；えすめい：验货被抓现行是开场转折——但加奈选择不揭发，暴露被"吞回去"也是一种写法）

## 七、与四段式骨架的对照（伪装段的写法）

| 阶段 | 私下段写法 | 公开伪装段写法 |
|---|---|---|
| ① 场景设定 | 写清谁不在（空窗） | 写清谁在场（伪装对象名单），人越熟伪装成本越高 |
| ② 日常动作 | 一个主活动+越界入口（辅导/看电视/洗澡） | 同一个主活动，动作全程正常，手的位置、坐的距离全对 |
| ③ 互动细节 | 停留接触+夹带档/越界档对话+眼神停留 | 正常接触（短快无停留）+正常档对话+眼神正常——**同一个动作写两遍，一遍停留一遍不收，就是两场戏** |
| ④ 收尾过渡 | 三种收法照常（正常/埋线/越界） | 收尾=切换瞬间：正常收尾（圆过去了，各回各屋）/埋线收尾（暗号留下没说破的话）/越界收尾（门一关就变脸，直接接私下段或H） |

- **环境双面性直接用**（模板"同一空间写两遍"）：客厅白天是全家看电视的地方，深夜是只剩两人的越界空间；切换点就是"人走完、灯调暗"的瞬间。
- **切换瞬间的弹选点**：每段公开伪装收尾时弹——"圆过去了（正常收尾）/ 暗号留钩（埋线收尾）/ 门一关就变脸（越界收尾）"三选一。

## 八、使用规则

1. **伪装必须可验证**：公开台词与私下台词要能对上（同一个称呼在两种场合有不同用法），动作在两种代码下都要有合理解释——穿帮细节读者能自己发现，就是好伪装。
2. **先私下后公开，禁跳步**：先建立私下关系（调教/亲密/支配的常态），再写公开伪装。伪装是"变质后"的维持手段，不是开场状态（堕落线阶段4才进入"日常=掩护"）。
3. **切换瞬间是必写点**：每场伪装戏必须有切换，要么差点暴露，要么暗号对上，二选一，不能只是"装了又装"。
4. **伪装对象分级**：家人（观察细、闯入快、最险）> 熟人邻居（会核对口径）> 陌生人（随便编但细节要自洽）——越熟越险，篇幅和张力按这个排序分配。
5. **案例只做参照**：素材来源的两部作品只是样本（人前装正常叔侄/全村面前被迫维持），手法可自由组合、改造、创新。
