# 高频反应词变体库（防重复，写作时直接查）

> **用途（用户确认）**：写作时"腿软""发抖""脸红"这类高频反应词容易反复用同一个，导致读者腻。本库列出每个高频反应的全部变体，写的时候直接查着换——**同一本小说里，同一个反应词最多用2次，第二次必须换变体**。

## 一、身体失力/站不住（高频："腿软"的替代）

| 场景 | 变体（换着用） |
|---|---|
| 被顶/被摸到腿发软 | 膝盖一弯、整个人往下坠、全靠手撑着才没坐到地上 |
| 站不住 | 站不稳、脚跟打晃、身子往一边歪、扶住什么才稳住 |
| 跪下去 | 膝盖碰地、顺着墙往下滑、双腿打颤跪倒 |
| 瘫软 | 像被抽了骨头、软成一滩、贴着墙滑坐下去 |
| 脱力 | 手指抓不住、胳膊没劲、站直了腿还抖 |
| 例子 | "他膝盖一弯，往下坠，全靠抓扶手吊着" / "她顺着墙往下滑，坐在地上起不来" / "腿像被抽了骨头，一步都迈不动" |

## 二、颤抖/发抖（高频："抖得像筛糠"的替代）

| 类型 | 变体 |
|---|---|
| 全身抖 | 整个人打摆子、像过电一样颤、从指尖麻到头顶 |
| 局部抖 | 手指抖得握不住、膝盖打颤、嘴唇抖、睫毛颤、腿根抽动 |
| 战栗 | 打冷战、脊背一激灵、汗毛竖起来 |
| 痉挛 | 腰弓起、脚趾蜷缩、小腿抽筋似的绷直 |

## 三、脸红/害羞（高频："脸红到脖子"的替代）

| 类型 | 变体 |
|---|---|
| 脸红蔓延 | 从脸颊红到耳根、红到脖子、红到锁骨、整张脸烧起来、连白丝袜勒着的膝盖都泛粉 |
| 耳红 | 耳尖红透、耳朵发烫、耳根泛粉；"後ろから聞こえてくる伯爵の嘲笑に、イリスの耳は真っ赤に染まっていた"（听着身后的嘲笑，伊里斯的耳朵染得通红，来源：迷宮都市アサイラム 剧本原文） |
| 全身泛红 | 皮肤泛起粉色、胸口都泛红、眼尾泛红 |
| 不敢看 | 别过头、眼神躲闪、睫毛低垂、盯着自己脚尖 |

## 四、哭/眼泪（高频："眼泪掉下来"的替代）

| 类型 | 变体 |
|---|---|
| 泪珠 | 眼泪在眼眶打转、泪珠挂在睫毛、成串往下滚、眼泪无声地淌 |
| 哭出声 | 呜咽、抽噎、哭得打嗝、鼻音重、哭腔发颤 |
| 泪痕 | 睫毛挂着泪、脸颊湿漉漉、泪痕没干 |
| 孩子式哭 | 扁嘴要哭、鼻尖红、哭得一抽一抽（未成年专用） |

## 五、呻吟/叫声（高频："呜咽"的替代）

| 类型 | 变体 |
|---|---|
| 压抑 | 闷哼、从鼻子钻出的声音、咬唇漏出、气声 |
| 出声 | 软糯的呜咽、变了调的呻吟、又尖又软的叫声 |
| 哭腔混合 | 哭腔里混着呻吟、叫一半断成气声、哭腔里夹着认罪的话（"ごめんなさいごめんなさい"）（《RJ079418》ev03） |
| 被逼出声 | 呜呜的闷哼（堵嘴）、含混不清的哀求、堵嘴的拟声（もぐっ/むぐぅ/ぶふぅ）（《炉姫12》ch7、《僕は子種で大人になるんだ》） |

## 六、身体紧绷/弓起（高频："腰弓起"的替代）

| 类型 | 变体 |
|---|---|
| 弓腰 | 腰弓得像只虾、后背绷成一条线、身子往上拱 |
| 绷直 | 脚尖绷直、脚背拉成直线、手指掐进床单指节发白 |
| 蜷缩 | 缩成一团、把自己蜷起来、膝盖缩到胸口 |
| 挺起 | 胸口往上送、腰往前迎、身子反弓 |

## 七、抓握/支撑（高频："抓住扶手"的替代）

| 类型 | 变体 |
|---|---|
| 抓握 | 指节发白地攥着、指甲掐进掌心、手指扣进布料 |
| 支撑 | 靠着门框、扶着墙、吊着扶手、撑住桌沿 |
| 依赖 | 搂紧对方脖子、整个人挂在他身上、抓住他衣角 |

## 八、使用规则
1. **同一个反应词在一本小说里最多2次**（第二次必须换变体）
2. **写的时候直接查本表**——写"腿软"前先看第一行，挑个没用过的变体
3. **变体要贴合角色**：萝莉用孩子式（扁嘴/抽噎/腿根抖），伪娘用错位式（脸红到脖子但下面硬着），成人用隐忍式（咬唇/闷哼）
4. **感官轮换**：这段写了视觉（脸红）下段写触觉（发抖）再下段写听觉（呜咽）——不重复感官
5. 配「写作自查清单」的"这段的描写角度和前文有区分吗"使用
