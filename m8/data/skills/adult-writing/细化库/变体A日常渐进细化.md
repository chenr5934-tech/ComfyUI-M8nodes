# 变体A日常渐进细化（借口接近型，2026-08-12）

> 核心卖点（用户确认）：**温水煮青蛙**——一切从最正常的日常动作开始，辅导功课、擦药、递东西、帮忙整理衣服，手"不小心"碰到，停留变久，呼吸变重，他还没反应过来，已经被慢慢吞掉。**信任是最好的陷阱**——他信任你，所以不会防备，直到越界才明白。
> 适用场景：家中/教室/辅导/照顾场景（乱伦慢热、信任型攻方）。
> 位置：`adult-writing\细化库\`，配套 H场景通用模板 变体A。

## 📐 结构（渐进主线）

```
① 日常场景建立（辅导/照顾/递东西）
② 正常接触（帮忙/检查/整理）
③ 接触变质（手停留久了/位置偏了/呼吸变了）
④ 他察觉不对（身体僵住/脸红/不敢动）
⑤ 越界（借口升级/直接动手）
```

**重心在③④**——从"正常接触"到"他察觉不对"的过程是这段的魂，慢慢来才色。

## 👤 攻方三种身份（谁在渐进）

### 1. 亲友型（父亲/哥哥/叔叔，乱伦线）
- 家中场景，辅导功课/帮忙擦药/整理衣服
- 信任最深，他完全不设防
- 变质点：手从肩膀滑到腰，从"帮你看看"变成"帮你弄弄"

### 2. 师长型（老师/教练/前辈）
- 教室/训练室/办公室，辅导/纠正姿势/检查
- 权威感+关心，他不敢拒绝
- 变质点：从"帮你调整姿势"变成"帮你放松肌肉"

### 3. 邻居/熟人型（隔壁哥哥/邻居叔叔）
- 家中/阳台/走廊，帮忙搬东西/修东西/照顾
- 日常感强，越界更突然
- 变质点：从"帮忙"变成"照顾"，距离越来越近

## 🎬 进入过程细化（动作级+台词级+反应级）

### 阶段1：正常接触（看不出问题）
- **动作**：坐在一起辅导功课/帮他擦药/递东西/整理衣服，距离正常
- **台词（攻方）**："这道题再看看""别动，我帮你擦""拿着"
- **反应（他）**：正常回应，没多想，完全信任

### 阶段2：接触变质（手停留久了/位置偏了）
**动作级**：
- 手停留时间变长：擦药从"擦完就松"变成"反复擦同一块地方"
- 位置偏移：从肩膀滑到腰，从腰滑到大腿内侧
- 距离变近：本来坐着的距离，慢慢凑近到能闻见对方身上的味道

**台词级（攻方）**：
- "这里也要擦一下……"（手往不该去的地方伸）
- "别乱动……快好了……"（越擦越久）
- "你放松点……"（声音变哑了）

**反应级（他）**：
- 身体僵住：本来在做别的事，突然停下了
- 脸红：不知道为什么，但脸开始发烫
- 不敢动：不是不想动，是不敢动，怕一动就……
- 心跳加速：自己都能听见，咚咚咚的

### 阶段3：他察觉不对（身体反应藏不住）
- **他看到了**：眼睛瞟到对方裤子鼓起来了，愣住
- **他的心理**："他……他怎么了？""是我多想了吗？""我是不是该躲开……"
- **身体反应**：想躲开但身体不听使唤，腿软，手抖
- **氛围**：空气变了，辅导变成了别的什么东西

### 阶段4：越界（借口升级/直接动手）
- **动作**：手从"擦"变成"摸"，从"摸"变成"揉"，借口"帮你放松"越界
- **台词（攻方）**："你身体好烫……是不是发烧了？我帮你看看……"
- **台词（他）**："不、不用了……我自己……"声音发颤
- **抵抗程度（按堕落阶段）**：
  - 前期：哭+推，"你干嘛……不要这样……"
  - 中期：半推半就，小声"你……你不是在帮我擦药吗……"但没真挣
  - 后期：主动，"你……你想要的话……"自己靠过去

## 🎯 被控方式（三走向写法）

### 堕落线
- **前期**：被控住——他没反应过来，已经被"照顾"的名义搂住/按住，愣住不敢动
- **中期**：停不下来——身体被开发了，停不下来，半推半就
- **后期**：自己想要——主动贴上去，求着要

### 纯暴力线
- **全程**：被控住——物理压制，力气悬殊，按住/压住/困住
- 他一直哭，一直挣扎，从不主动
- 攻方一直暴力，没有温情

### 纯轮奸线
- **全程**：被控住——被多人按住，换人时也不松
- 他哭到失声/麻木
- 攻方们轮流上，交接时也不放松

## 🎤 交锋台词（按阶段/走向分）

### 攻方台词库

**正常阶段（渐进中）**：
- "别动……我帮你看看……"
- "这道题不会吗？过来一点……"
- "你这里红了……我帮你擦擦……"

**变质阶段（手开始乱摸）**：
- "这里也要……你放松点……"
- "你身体好烫……是不是不舒服？"
- "别怕……就一下……"

**越界阶段（直接动手）**：
- "你这样子……我忍不住了……"
- "别出声……就一下……"
- "你不是也想要吗？……身体都这样了……"

### 受方反应（按走向分）

**堕落线**：
- 前期："你干嘛……不要这样……"（哭着推，推不动）
- 中期："你……你不是在帮我擦药吗……"（小声，没真挣）
- 后期："你……你想要的话……"（自己靠过去）

**纯暴力线**：
- "滚开！不要碰我！"（一直哭，一直挣扎）
- "救命……有人吗……"（喊到嗓子哑）

**纯轮奸线**：
- "求求你们……放过我……"（哭着求饶）
- "不要了……真的不要了……"（麻木，已经没力气挣扎）

## 🎲 弹选点（日常渐进专属）

- **接触方式**：A. 辅导功课（手从肩膀滑到腰） B. 擦药/检查（手从皮肤滑到不该去的地方） C. 整理衣服（借口"衣服皱了"直接动手）（弹选）
- **他察觉时机**：A. 手碰到敏感部位才反应过来 B. 看到对方反应（裤子鼓了）才明白 C. 一直没察觉，直到被按住才反应过来（弹选）
- **越界借口**：A. "你身体好烫……我帮你看看" B. "别动……快好了……" C. 不找借口，直接动手（弹选）
- **他是否点破**：A. 装作没看到（心照不宣） B. 小声说"你……你在干什么……" C. 直接推开（弹选）

## 📋 场景卡示例（亲友型：家中辅导，慢慢渐进版）

**① 设定**：晚上家中，他穿家居服（短裤+宽松T恤），在客厅桌上写作业，爸爸坐旁边辅导
**② 开场**：他趴在桌上写数学，爸爸坐旁边看手机，偶尔抬头看看他写的对不对
**③ 进入（变体A）**：爸爸伸手过来指着题目："这道题再看看……"手没缩回去，搭在他肩膀上。他没多想，继续写。爸爸的手开始轻轻拍他肩膀，像在哄他。
**④ 被控（被控住）**：爸爸的手从肩膀滑到腰，他写字的手停了一下，但没说什么。爸爸凑近了一点："写累了吧？肩膀酸不酸？我帮你捏捏。"他点头。爸爸的手开始捏他肩膀，越来越用力，位置越来越往下。
**⑤ 交锋**：爸爸的手滑到他T恤下摆，"衣服都皱了……帮你弄弄。"他身体僵住了，"不、不用了……我自己……"爸爸没停，手伸进T恤里，"别动……就一下……"

**⑥ 弹选去向（按堕落阶段分）**：

**前期（被迫，选项带害怕）**：
- A. "爸……爸……你在干什么……"（声音发抖，想推开他的手，但推不动）
- B. "我、我作业写完了……我先回房间了……"（站起来想跑，腿软又坐回去）
- C. "别……别这样……我害怕……"（缩成一团，不敢看他）

**中期（半推半就，选项带犹豫）**：
- A. "爸……你不是在帮我捏肩吗……"（小声问，却没躲开他的手）
- B. "我、我有点热……"（扯了扯T恤，却没阻止他的手）
- C. "你……你别这样……被人看到……"（说归说，人没动）

**后期（主动勾引，选项骚一点）**：
- A. "爸爸……人家的鸡巴硬了……你摸摸嘛～"（拉着他的手往自己腿间带）
- B. "爸爸……你是不是想要人家……"（转过身，面对面看他，脸红红的）
- C. "爸爸……人家下面流水了……你看看……"（自己把短裤拉下来一点）

**⑦ 主玩法（弹选，可多选）**：
- **前期**：强制口交（被按着头） / 后入（趴桌上哭） / 掐脖后入（翻白眼）
- **中期**：半推口交（说着"就这一次"自己跪下） / 骑乘（面对面坐着） / 乳交（蹭胸口）
- **后期**：主动口交（自己跪着抬头看他） / 抱操（搂着脖子站着操） / 内射夹紧（"都给你了……"）

**⑧ 射精（弹选）**：
- **前期**：内射（射完被吓哭） / 口爆（被按着头全咽） / 颜射（精液糊在哭花的脸上）
- **中期**：内射（他小声说"又弄里面了……"） / 射身上（"又弄脏了……"） / 吞精（自己咽下去）
- **后期**：内射夹紧（"都射进来……人家都接住……"） / 颜射（主动张嘴接着） / 射脸上（"爸爸射得好多……"）

**⑨ 收尾**：他瘫在椅子上，短裤褪到膝盖，T恤撩到胸口，哭得打嗝。爸爸给他把衣服拉好，揉揉他头发："早点睡吧。"——【长篇后续：爸爸=加害者双面暗线，辅导=做的暗号建立】

## 📏 日常变质的具体手法（来源：SKILL.md 二·五「日常变质的具体手法」）

> 变体A是"温水煮青蛙"，下面的手法全是"慢慢变质"的操作细节，配合上面的渐进结构用，禁止跳步。

- **用日常动作做掩护**：辅导功课、看电视、擦药、睡前晚安、生病照料——越界都发生在"例行公事"里，动作本身正常，手放的位置不正常
- **借"关心"之名**："你冷了加件衣服""头发乱了帮你理理""膝盖疼帮你揉揉"——照顾的名义是越界最好的入口，说关心的话、做越界的手
- **环境清场**：灯调暗、门关上、窗帘拉上、音乐电视声开大——环境为越界"清场"，也让读者感觉到"要出事了"
- **时间点选择**：夜晚、酒后、生病时、对方睡着后、独处时——利用"非常时刻"降低防御
- **受方反应线（关键节点）**：身体僵硬→假装没注意→默许不反抗→主动贴近→主动索取——他的"不反抗"是变质能否继续的分水岭，每一步写清心理（困惑/害怕/羞耻/期待）
- **攻方试探递进**："他应该没发现吧"→"我是不是太过分了"→"他已经默许了"→"这是我们的日常"——用内心独白写试探的自我合理化
- **变质的速度控制**：可以一步一顿（每次越界隔好几章日常）也可以连续升级（几章内完成）——按题材定，长篇用慢热，短篇用快速

## 🔗 渐进接触层级（来源：SKILL.md 前戏与渐进反应库「接触的渐进层级」）

> 变体A的"手从肩膀滑到腰"就是沿着这条层级走——每多一级，他的反应多暴露一分。

1. **安全接触**：碰手/搂肩/搭腰（"不经意地碰到他的手""手搭在他腰上没拿开"）——正常动作，但停留时间变长
2. **隔衣越界**：隔衣摸敏感部位（"隔着衣服按上他的臀""隔衣握住他胸口的隆起"）——还没伸进去，但意图明确
3. **伸入**：手伸进衣服/裤腰（"手指顺着衣摆探进去""从裤腰摸上大腿内侧"）——正式越界开始
4. **贴身摩擦**：隔裤/隔内裤磨蹭（"他的硬挺隔着裤子顶着他""磨蹭着越来越湿"）——双方都感受到对方
5. **脱衣/露体**：脱掉外衣/内裤（"把内裤褪到膝弯""解开扣子"）——身体暴露，防线失守
6. **口舌接触**：亲吻/舔弄（"从嘴唇亲到脖子""舌尖舔过锁骨"）——从前戏到正戏的过渡

> **配合受方前戏反应**（来源：前戏与渐进反应库）：身体反应渐进——先是僵硬（"身体僵住不敢动"）→ 发软（"腿软得站不住"）→ 发热（"皮肤发烫"）→ 湿润/勃起（"腿心湿了""那处硬了起来"）——受方的反应随前戏加深逐步暴露；呼吸变乱→轻哼→呻吟是声音的渐进暴露。

## 使用注意

1. **重心在渐进过程**——正常接触→手停留久→位置偏了→他察觉不对→越界，慢慢来才色
2. **信任是最好的陷阱**——他信任你，所以不会防备，直到越界才明白
3. **攻方的内心挣扎要短而真**——"我在干什么""他是我看着长大的"这类独白穿插，别长篇大论
4. **他察觉的过程要细**——身体僵住/脸红/不敢动/心跳加速，这些细节比直接写硬的更色
5. **抵抗按堕落阶段**——前期哭+推，中期半推半就，后期主动
6. **越界不是重点**——没有"变脸"那一下，是慢慢变质到底
