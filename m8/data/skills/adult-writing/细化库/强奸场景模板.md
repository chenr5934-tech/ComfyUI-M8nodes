# 强奸场景模板（八段式骨架 + 暴力强度分级 + 纯暴力线专用，2026-08-12）

> **定位（用户明确）**：纯暴力线（H模板三走向里的B线）专用模板。从头到尾暴力/强迫/物化，**无堕落弧线**，受方全程被迫（哭/挣扎/反抗）。**可以写被迫的生理反应（身体诚实但心理抗拒）**——被硬闯却流水/被操到高潮，反差带来更深的羞耻绝望，不是堕落快感；但绝不走向"接受→主动"。与堕落线的区别：堕落线"身体诚实→接受→主动"，本线"身体被迫反应→心理始终抗拒→羞耻绝望加深"。案例见下"受方反应"部分。与H场景通用模板的九段式骨架配套，这里做简化+暴力化。轮奸类场景另见 `轮奸场景模板.md`。
> **先定走向再写**：本篇只服务B纯暴力线。如果故事走A堕落线（身体诚实/接受/主动求欢），去用H通用模板的堕落线写法，别用本模板。

## 📋 八段式骨架（固定）

```
① 设定 → ② 开场（可极短） → ③ 袭击进入 → ④ 暴力压制
→ ⑤ 撕扯/反抗 → ⑥ 主玩法（按暴力强度分级） → ⑦ 射精 → ⑧ 收尾抛下
```

| 段 | 内容 | 写法要点 |
|---|---|---|
| ① 设定 | 谁/在哪/什么关系/力气差距 | 攻方和受方的体力差距直接写出来（体型/力气悬殊），这是后面"反抗没用"的前提 |
| ② 开场 | 可极短，一两句话交代环境 | 纯暴力线不做日常铺垫，给个地点和状态就够（"放学的巷子""夜里回家"），环境给一个感官锚点（暗/冷/没人） |
| ③ 袭击进入 | 怎么被抓住的 | 从后面捂住嘴拖走/按倒/堵路拽进暗处，没有试探，开场即暴力 |
| ④ 暴力压制 | 身体被控制住 | 物理压制写实：捂嘴、扣手腕、按肩膀、膝盖压腿。压制的动作和受方挣不开的反应一起写 |
| ⑤ 撕扯/反抗 | 撕衣服 + 受方反抗 + 攻方加力 | 撕扯和反抗交叉写：她抓挠踢蹬，他加力/扇耳光/掐脖子把她打服。反抗越狠压制越狠 |
| ⑥ 主玩法 | 按暴力强度分级（见下） | 先定强度级再写。全程保持"强迫感"，攻方不会停下来问感受 |
| ⑦ 射精 | 射在哪/量/收尾动作 | 射完不温情，直接进入⑧ |
| ⑧ 收尾抛下 | 丢下她/威胁/提裤子走人 | 攻方提裤子/系腰带/丢句话就走，受方瘫在原地。长篇可弹后续（下次还来/威胁保密） |

## 💥 暴力强度分级（轻→重，先定级再写⑥）

> 每一级是"压制手段+受方反抗+攻方反应"的整体风格，不是单点。强度可在一场里升级（从压制型打到殴打威胁型），但别跳级到莫名其妙。

### 一级：压制型（轻·纯力气）
- **压制手段**：靠体重和力气，不主动动手打——按倒、骑在身上压住、捂嘴、单手扣两只手腕按在头顶
- **反抗与反应**：她四肢乱蹬、扭腰拱背想掀翻他，他加大重量压下去，喘着粗气说"别动"
- **写法要点**：写"力气悬殊"——她挣得脸憋红，他纹丝不动；写被压住后只剩腿还能蹬，腿也被他膝盖压住，整个人钉死在地上
- **适用**：攻方不追求折磨，只求速战速决；力气差距大的场景
- 例句："他整个人压上来，一只手就把她两只手腕攥在一起按在头顶。她蹬着腿想把他踹开，他膝盖一压，两条腿也被钉死了，她只能扭着腰，一下都动不了。"
- 来源：《强姦小蘿莉》《糙汉爸爸》

### 二级：撕扯型（中·衣服与皮肤）
- **压制手段**：一级的力气压制 + 撕衣服/掐脖子/抓头发，身上留下掐痕抓痕
- **反抗与反应**：她拼命护着衣服/抓他脸/咬他手，他掐她脖子或抓她头发把她的头按下去，撕衣服的速度更快
- **写法要点**：写布料撕裂的声音（"嘶"的一声，扣子崩开）、写她护不住的无助（"抓着被撕开的领口，又被一把扯开"）、写掐痕（脖子上留下手指印）
- **适用**：攻方享受"剥开"的过程；场景里有衣服可撕（校服/裙子/丝袜）
- 例句："他抓住她领口往两边一扯，扣子崩了一地。她下意识并拢腿去护，被他抓着头发把脑袋按在地上，'再动把你衣服全撕光'。"
- 来源：《强姦小蘿莉》《强奸女儿》（道具制伏）、《遊览车的绑架轮奸》

### 三级：殴打威胁型（重·打服为止）
- **压制手段**：二级手段 + 掌掴/拳打/踢踹，用痛觉压服反抗
- **反抗与反应**：她激烈反抗/喊叫，他扇耳光打服，边打边威胁（"喊就弄死你""再叫打死你"）；她被打蒙了，耳朵嗡鸣，不敢出声只剩抽噎
- **写法要点**：写掌掴的声音和力度（"啪"的一声，脸被打偏到一边）、写她被打后的状态（眼泪哗哗流、嘴唇抖、不敢喊了）；威胁话术要具体（"再喊一嗓子试试"）
- **适用**：攻方暴虐型；受方反抗激烈的场景
- 例句："她刚喊出半个音，一巴掌甩过来，脸都被打偏了。她捂着被打的那半边脸，哭都不敢出声了。他掐着她下巴把她的脸扳回来，'再喊，下一巴掌更狠'。"
- 来源：《强姦小蘿莉》《糙汉爸爸》《刁女調教手冊》

### 四级：器械型（最重·工具制伏）
- **压制手段**：用工具制伏——刀抵脖子、皮带抽、绳子绑、布条堵嘴
- **反抗与反应**：她看到刀就僵住了，哭都不敢大声；被绑住后彻底放弃挣扎，只剩发抖
- **写法要点**：写"恐惧压过反抗"的转折（刀一亮出来，她攥紧的拳头松开了）；写工具的触感（冰凉的刀面贴脖子、绳子勒进手腕）；写堵嘴后的声音（只能呜呜）
- **适用**：绑架式强暴；攻方控制欲强/要长时间施暴
- 例句："冰凉的刀面贴上她脖子，她整个人僵住了，举着的手慢慢放下来。他拿布条把她的嘴勒住，又用绳子把她手腕绑在栏杆上，'老实点，不然这刀可不长眼'。"
- 来源：《強姦女兒》《遊览车的绑架轮奸》《爸爸强暴我的自白》

## 🫥 受方反应（纯暴力版·被迫的生理反应）

> **铁律（2026-08-12 用户确认更新）**：纯暴力线**可以写受方快感**，但只写"不情愿的那种、被迫有感觉"——**身体诚实但心理抗拒**。心理上一直是厌恶/恐惧/屈辱/绝望；身体上可以出现流水/湿润/勃起/被操到高潮（被迫的、不受控制的）。**核心是反差**："明明不想，身体却……""被强奸却还……"——反差带来的是**更深的羞耻和绝望**，不是堕落快感。身体反应不走向"接受→主动"。

| 阶段 | 反应 | 写法要点 |
|---|---|---|
| 挣扎 | 四肢乱蹬、抓挠、踢踹、扭腰拱背 | 动作写具体（指甲抓他手臂/蹬腿踹他肚子），写"挣不开"的力气差距 |
| 哭喊 | 尖叫、哭喊救命、被捂嘴后只剩呜呜 | 哭喊被捂嘴打断；喊救命被威胁吓回去（"再喊杀了你"） |
| 求饶 | 哭着说"求你放过我""别这样" | 求饶越哭越被操，攻方不理会或威胁；求饶是她的挣扎不是妥协 |
| 麻木 | 哭到没力气、眼神空了、身体不反抗了 | **麻木≠享受**：写"像死了一样任人摆布"，写她盯着天花板/墙角发呆，眼泪自己往下掉；就算被操到高潮也是纯生理反应，脸上没有快感的表情，眼泪照样流 |
| 身体反应 | 痛（抽痛/撕裂感）、发抖、无力、发冷；**被迫的生理反应**（被硬闯却湿了/流水/被操到高潮） | 痛感写实（"干涩的疼""撑开的疼"），因为她不湿，是硬闯，所以痛是主要的身体感受；**被迫反应写法**："明明不想，身体却湿了""被强奸却高潮了"——写她对自己的身体又羞又恨，越有反应越绝望 |

**三个禁写（2026-08-12 更新）**：
1. **禁写"主动"**——身体可以被迫反应（湿/勃起/被操到高潮），但动作上绝不主动迎、不夹着求、不自己配合
2. **禁写"心理接受"**——"身体背叛意志"的拉扯可以写（那是本线的核心张力），但心理始终抗拒，绝不走向"算了/认了/想要"
3. **禁写她中途变得配合**（除非是"被打怕了不敢动"的麻木，麻木也要写成"死"的，不是"顺"的）——被迫高潮≠配合，写"身体自己高潮了，她心里更恨"

**被迫生理反应案例（2026-08-12 用户确认，直接参考）**：
- 《电车痴汉与公厕》："明明是被恶心的陌生男人奸淫，自己的小穴却本能地产生了生理反应""被强奸却还……"——身体反应带来更深绝望
- 《苏小野》："嘴里说着不要，下面却在流淫水""明明被强暴却高潮了"——身体诚实矛盾
- 《公车上的高潮》："被抚摸的感觉很复杂，其实很舒服""虽然心里厌恶，但身体却做出不同反应"
- 《电车之狼》："死命咬着唇抵抗快感"→被迫说骚话→身体贪婪夹紧——身体背叛意志
- 《伪娘与黑人》："既紧张又害怕，小肉棒却不争气的变得更硬"——伪娘特有双重心理（身体被当女人玩弄的屈辱+男性器官被刺激的本能快感）

### 施暴方的暴力型写法（来源：SKILL.md 男性施暴方反应库）

> 纯暴力线攻方主要用"粗暴型"，生理+心理+语言三线并写——一个施暴场景三线同时推进，比只写动作更有层次。

**生理线**：
- 勃起状态：入戏前就硬（"隔着裤子都顶出形状"）、被抗拒/求饶刺激得更硬（"她越哭他越硬"——反抗对施暴方的催情作用）
- 抽插动作：快慢节奏（"先是慢慢地碾，再猛地加速"）、深浅控制（"整根没入再整根拔出，只留龟头在穴口磨"）、用力程度（"撞得她整个人往前顶"）
- 射精反应："闷哼一声，死死顶在最深处射了出来"，射完还在缓缓抽动不急着拔出来
- 体力/持久："一遍又一遍，不知疲倦"、越紧越兴奋撞得更狠

**心理线**：
- 征服快感：占有/支配的快感（"她是我的了""看你还怎么逃"）——核心快感来源是"征服"而非"性交"本身
- 权力感：对受方身体/反应/声音的控制欲（"他要她叫她就得叫""他命令张开腿，对方只能照做"）——控制即快感
- 物化视角：把她当物品（"就是个肉便器""泄欲的工具"）——物化是施暴方的心理防御，也是兽欲的合法化
- 兽欲/失控：从理智到兽欲的滑落（"一开始还算克制，后来完全被欲望支配"）——"野兽化"是施暴方的堕落线

**粗暴型写法**：暴力动作多（撕衣/掐脖/猛撞）、语言凶狠、表情狰狞——纯粹的暴力宣泄；她越哭他越硬、反抗当燃料（"一想到强奸就兴奋"）——快感来自支配，不是来自她配合

### 辱骂分级·中度（来源：SKILL.md 辱骂程度分级）

> 强暴/调教主场景、堕落期标配——中度辱骂贯穿全程，选强度时从对应级别取词，级别越高用词越脏、驯化性越强。

- **物化称呼**："骚货""母狗""肉便器"——称呼本身就是驯化
- **反应羞辱**："被强奸都能湿""还装清纯""嘴上说不要，下面咬这么紧"——用她的身体诚实打她的嘴硬
- **年龄碾压**（未成年受方）："12岁就这么骚""小孩子就该被大人操"——用年龄差本身羞辱
- **身份打击**："你妈都没你这么放荡""穿成这样不就是给人操的""平时挺清高的，现在不也张着腿求操"
- **受方娇痴骂配中度**（来源：被操者的骂＝娇痴）：边哭边骂（"你个变态……呜……别碰我……"）、求饶夹杂骂（"禽兽……轻点……"）——骂声被撞碎，比完整骂更有味

### 事后的写法（来源：SKILL.md 通用事后处理库「压抑崩溃型」+ 二·六手法十）

> 强暴事后是情绪落点，决定读者读完是"压抑窒息"还是"爽完空虚"——纯暴力线走压抑崩溃型。

- **受方瘫软**："她躺在床上，眼神空洞地望着天花板""缩在墙角，好半天才哭出声"；强撑收拾（穿衣服/清理/装作没事）和白天正常生活衔接，强化分裂感
- **施暴方冷漠**："他提上裤子就走了，像什么都没发生"——施暴者的事后动作：提裤子/清理/点烟/威胁（"不许说出去"）/约定下次（"明天还来"）——事后越平淡越恐怖
- **环境狼藉**："床单凌乱，地上散着被撕破的衣物""空气里还残留着那股味道"——用环境定格"刚刚发生了什么"
- **身体痕迹**：红肿/精液/爱液/汗湿/齿痕红印（"大腿内侧的红印""腿间合不拢的感觉"）——身体的"事后"证据
- **事后对话**：施暴者离开前可能丢下一句话（"乖女儿，睡吧"——最温柔的威胁最有杀伤力）
- **事后衔接**：收拾完装没事，回到正常生活（"第二天早上，她还是那个乖乖的学生"）——"白天演正常"的分裂感；或威胁/约定为下一场埋线（"他走的时候说，明天还来"）

## 📇 场景卡示例

### 场景卡1：陌生人强暴（深夜小巷·直接强暴变体）

- **① 设定**：放学夜路，她穿校服，被尾随的陌生男人拖进巷子。男人力气大她一截，她没处跑
- **② 开场**：巷子里路灯坏了，黑得伸手不见五指，她加快脚步想赶紧走出去
- **③ 袭击进入**：突然一只手从后面捂住她的嘴，把她整个人往后拖，脚离了地。她手里的书包掉在地上
- **④ 暴力压制**：被按在墙上，男人一只手捂嘴，另一只手把她两只手腕攥住压在头顶。她挣，纹丝不动
- **⑤ 撕扯/反抗**：他空出手撕她校服领口，扣子崩开。她拼命扭，抬腿踹他，被他用膝盖顶住大腿根压回去，掐住她脖子，"再动掐死你"
- **⑥ 主玩法（二级撕扯型→三级）**：她喊不出声，眼泪糊了一脸。他扯下内裤，硬闯进去。她疼得弓起背，指甲抠进他手臂，他闷哼一声掐着她脖子不松手，撞得更狠，她抠出来的血他都顾不上
- **⑦ 射精**：他低吼一声死死顶住，一股股射在里面。他喘了两口气，才慢慢退出来
- **⑧ 收尾抛下**：他提上裤子，看了眼瘫在墙根的她，"敢说出去，下次弄死你"。脚步声走远。她缩在墙角，校服撕烂了，浑身发抖，好半天才哭出声
- 来源：《强姦小蘿莉》《遊览车的绑架轮奸》

### 场景卡2：熟人/父亲强暴（家里·无声强暴）

- **① 设定**：她放暑假在家，父亲趁母亲上夜班，锁了房门。她怕他，从小怕
- **② 开场**：客厅里父亲坐在沙发上看电视，她洗完澡想回自己房间，路过客厅时父亲叫住她，"过来，爸有话跟你说"
- **③ 袭击进入**：她刚走近，父亲一把抓住她手腕把她拽倒在沙发上。她愣住，第一反应是笑，"爸你干嘛"——笑到一半看见他脸色不对，笑不出来了
- **④ 暴力压制**：父亲整个人压上来，一只手捂住她的嘴，"别叫，你妈在楼下打麻将，叫了也没人来"。她掰他手指，掰不开
- **⑤ 撕扯/反抗**：他扯掉她睡裙，她拼命踢，被他用大腿压住两条腿。她掐他胳膊，他反手一巴掌，"反了你了"。她被打蒙，捂着脸哭，不敢再动
- **⑥ 主玩法（三级殴打威胁型）**：他扯下裤子，分开她腿硬顶进去。她疼得弓起身哭喊，被他一巴掌又打回去，"再喊还打"。他一边操一边压着她，全程不说话，就喘粗气，她哭得打嗝，他充耳不闻，越哭越用力
- **⑦ 射精**：他闷哼一声射在里面，压着她又停了几秒才退出来，一股精液顺着大腿流到沙发上
- **⑧ 收尾抛下**：他提上裤子，打开门扔下一句"擦干净，你妈回来之前收拾好"。她趴在沙发上，睡裙撕烂了，大腿根又痛又黏，听到客厅传来他换台的声音，像什么都没发生过
- 来源：《強姦女兒》《我迷奸了亲生女儿》《糙汉爸爸》

## ⚖️ 与堕落线的区别对照表（同一场景，两条线的写法）

> 写之前对照这张表自查：走纯暴力线却写了左列的写法，就是串线了。

| 环节 | 堕落线（A）怎么写 | 纯暴力线（B·本模板）怎么写 |
|---|---|---|
| 受方身体反应 | 身体诚实：湿了/夹紧/忍不住呻吟/高潮，"嘴上抗拒身体背叛"是核心张力 | **被迫的生理反应**：可以写湿/流水/勃起/被操到高潮，但全是被迫的、不受控制的；"明明不想，身体却……"的反差带来更深的羞耻绝望；痛/怕/麻/无力照写，硬闯的痛和被迫的反应可以并存 |
| 受方心理 | 有弧线：抗拒→动摇→接受→沉沦（"停不下来"到"自己想要"） | 无弧线：全程被迫，从挣扎到哭喊到求饶到麻木，心理始终抗拒；身体有被迫反应但心理不松动，羞耻绝望越来越深 |
| 攻方态度 | 可能混有温柔哄骗/事后温存/"爸爸爱你才这样" | 全程暴力/威胁/冷漠/物化，事后提裤子走人 |
| 攻方语言 | 调教话术+逼她回应（"叫哥哥""说你是我的"） | 威胁+命令+羞辱（"喊就弄死你""再动打死你""贱货"），不问感受 |
| 被控三态 | "被控住"→"停不下来"→"自己想要"递进 | 只用"被控住"，一直物理压制不松手 |
| 收尾 | 威胁保密/约定下次/日常化/驯化，关系往下延续 | 抛下/威胁/提裤子走人，她瘫在原地，关系不温存也不延续 |
| 弹选节奏 | 去向/玩法/射精都弹，后期不弹（已成习惯） | 照弹（去向/玩法/射精），⑧收尾弹"下次还来/威胁保密/就这么走了" |
| 读者情绪落点 | 爽/堕落的刺激感 | 压抑/窒息/恐惧/绝望感（身体被迫反应加深绝望） |

## 使用规则

1. **先确认走向再套模板**：用户没要堕落、只要暴力 → 走本模板，不套堕落三阶段
2. **八段固定，强度分级可升级**：一场里可以从一级打到三级，但别跳级
3. **受方三禁（更新）**：禁主动/禁心理接受/禁中途配合（身体可以被迫反应——湿/勃起/被操到高潮，但动作不主动、心理不松动；麻木写成"死"的，不是"顺"的）
4. **攻方类型可参考** `男性施暴方反应库_细化版.md`（粗暴/冷漠/温柔哄骗/变态玩味——但本模板下"温柔哄骗型"要慎用，那是堕落线的；纯暴力线主要用粗暴/冷漠/变态玩味）
5. **弹选节奏**：⑥主玩法弹候选（按强度级预配），⑦射精每次弹，⑧收尾按长篇短篇决定弹不弹
6. **衔接轮奸**：单人强暴中途有人加入/被拖去更多人处 → 转 `轮奸场景模板.md`（见该文件"与强奸模板的衔接"一节）
