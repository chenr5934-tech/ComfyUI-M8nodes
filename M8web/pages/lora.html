LoRA Inspector

Drop in a .safetensors file and read back its training parameters and training tags.

The file is never uploaded and never written to disk. Parsing reads only the beginning of the file (usually a few KB to a few tens of KB) and drops the reference afterwards - even a several-hundred-MB model takes an instant, because not a single byte of tensor data is read.

＋ Click to choose, drag it in, or paste with Ctrl+V Only .safetensors files
