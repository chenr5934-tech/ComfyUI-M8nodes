Pixel Art Conversion

Compress an image into low-resolution pixel art: antialiasing convolution, area-average downsampling, sharpening convolution, colour-reduction dithering, nearest-neighbour upscale. Everything is computed on this machine and the image is never uploaded.

The upscale uses nearest-neighbour, not interpolation. Interpolation blurs the boundary between pixels, which gives you a low-resolution image rather than pixel art. "Pixel block size" is how many source pixels each pixel covers - larger means coarser grain.
